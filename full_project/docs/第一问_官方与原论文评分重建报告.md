# MathorCup A题第一问：原论文原始评分辅助的官方题目重建

## 结论

官方要求依据 `1.csv` 的化学特征，输出 `3.xlsx` 定义的 Aroma/Flavour 0–6 分。该评分卡目前共 30 项 A/F 字段（另有20项其他感官），不能将 `4.csv` 的标准化连续值直接四舍五入当作分数。

原论文原始文件 `Raw sensory data anonymized.csv` 是**外部公开参考数据**，内容为 2197 条逐评分员的真实 0–6 分，250 款啤酒每款3–31次评分。其上传文件 MD5 与论文 Zenodo 版本一致：`a8f911d8c0061e096abf3b087678e164`。

> 论文来源：Schreurs et al., Predicting and improving complex beer flavor through machine learning, Nature Communications 15:2368 (2024), https://doi.org/10.1038/s41467-024-46346-0；数据仓库 https://zenodo.org/records/10653704 。

## 标签定义及评分卡利用

- 真实个体分数 `s_(i,t,j) ∈ {0,1,…,6}`；参考目标为每款啤酒每项感官的评分员均值 `y_(i,j) = mean_t(s_(i,t,j))`。
- 使用匿名编号 `beer_name=1…250` 映射官方 `1.csv` / `4.csv` 的**物理行号**，而非带科学计数格式的 beer_id。对应依据：50维参考均值与 `4.csv` 目标的逐维Pearson相关范围0.9041–0.9934，中位0.9777，随机关联100次的最高中位相关仅0.0419。
- 官方 `3.xlsx` 给出评分字段结构：六个父类总体强度，各带4个细分子项。2197条原始评分的每个非零子项等于其父项（14989个非零子分，0违反）。多输出ExtraTrees以叶节点非负加权平均输出，因此该父子不等式自动成立，无需强制堆叠模块。
- 模型每次只看 `1.csv` 231化学指标；风格仅用于交叉验证分层。`4.csv` 的官方标准化数值和原论文评分只作为训练监督（分别不同实验），绝不能作为化学输入特征。

## 严格的两条路线

方案A（外部参考监督）：`化学X → 原始评分均值 y → 取整0..6`。

方案B（官方标准化监督）：`化学X → 4.csv标准化Z`，再在**每折训练啤酒**上用对应原始 `Z,y` 拟合逐维仿射标定 `y≈a+bZ`，将测试啤酒的模型预测 `Z_hat` 映射为 `y_hat` 并取整。评分标定绝不使用验证啤酒的 `y`。

算法：均值、Ridge(alpha=100；输入中位数填补及训练折标准化)、ExtraTrees（260树、每叶最小2、max_features=0.7），预先固定，全部五折训练。

分折：250款啤酒、5折，每折200训练50验证，按官方22风格分层（样本不足5的风格归入稀有组用于分层）。各折填充与模型只在训练啤酒拟合。所有250款输出均为**OOF折外预测**，不能把这些外部原始分数视为独立数据集验证。

## 本轮重新实测

| 模型 | 30维A/F MAE | 全50维MAE | 30维取整准确率 | 30维差≤1 |
|---|---:|---:|---:|---:|
| MeanRaw | 0.604948 | 0.548788 | 46.23% | 92.67% |
| RidgeRaw | 0.558377 | 0.491577 | 51.31% | 93.56% |
| ExtraTrees→Raw | **0.506231** | **0.442372** | **53.93%** | **95.19%** |
| ExtraTrees→官方Z→标定 | 0.514076 | 0.447752 | 53.13% | 94.93% |
| Ridge→官方Z→标定 | 0.561060 | 0.494560 | 50.72% | 93.27% |

独立计算 `4.csv` 50项z值预测：ExtraTrees五折OOF MAE=0.339532（标准化单位）；不得与原始0–6分的MAE直接比较。

对ExtraTrees两条路线，按250款啤酒配对Bootstrap 1万次，`官方Z校准 − 直接Raw` 30维MAE差为+0.007846，95% CI=[+0.004861,+0.010858]。提示本次固定五折预测下直接原始监督有小幅优势；置信区间不覆盖换划分、重调参后的训练不确定性。

原始评分员与同款其他评分员均值之间的30项平均MAE（逐人留一）为1.0654。它用于量化品评员分歧，不能被直接称为模型可达误差下界。

## 创新是否成立

- **有可靠依据**：外部评分源头与官方样本对齐，逐评分员层次评分结构，折内Z→原分标定。
- **已验证的经验结论**：直接原分监督略优于当前简单的标准化监督加仿射标定；树模型较Ridge有明显优势。
- **尚未证实的创新**：多任务深度网络 / 自适应特征共享模型能改善官方第一问的预测性能。此前测试没有支持，不应编造提升。
- **不成立的说法**：拿回原论文同一批250款啤酒的真实评分后，直接输出这些均值并称其为新啤酒预测；将原始评分文件说成官方发放；以多个模型的交叉验证成绩当独立测试性能。

## 文件说明

- `q1_reference_rebuild.py`：主实验完整代码。脚本依赖 Python、NumPy 和 scikit-learn（无需pandas）。
- `scorecard_schema.json`：根据官方 `3.xlsx` 评分卡列名核对得到的50个字段及类型。
- `results/audit_results.json`：来源与映射审计、模型比较、误差区间。
- `results/q1_AF30_oof_integer_250.csv`：**本问推荐的250×30整数折外预测**，不是标签拷贝。
- `results/q1_AF30_oof_scores_250.csv`：250×30连续0–6评分折外预测。
- `results/ETRaw_oof_integer_250.csv`：250×50整数预测，包含20个额外属性。
- `results/reference_raw_panel_means_250.csv`：真实参考标签，仅用于评估、核查，严禁误当预测结果。
- `results/split_assignments.csv`：250款啤酒的折号、原行号、风格和原始评分条数。

## 运行方式

```bash
pip install numpy scikit-learn
python q1_reference_rebuild.py --data-dir "原始附件所在目录" --out-dir results
```

原始附件目录需包含 `1.csv`、`4.csv`、`Raw sensory data anonymized.csv`，带有 `(1)` 等后缀的用户上传文件也可自动定位。`3.xlsx`的评分卡列名已经冻结在脚本同目录的 `scorecard_schema.json` 内供复核。

## 竞赛写作与公允性

该外部原始评分文件是赛题同批250款啤酒的感官原始答案，不具备独立数据集检验性质。论文必须引用原论文、明确外部参考数据来源、说明模型预测与真实评分的区别。模型的实际泛化只能通过按啤酒分折的OOF评价初步估计，无法声称对新实验室/新风格啤酒有效。竞赛AI使用的透明披露仍需遵守。

本包属于AI辅助的数据审计、研究方案与代码草案；竞赛规则要求参赛队员独立完成核心建模、求解和分析，并审查、改写及确认所有结果。
