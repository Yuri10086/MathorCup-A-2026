# 2026 MathorCup赛道A·第二问：有符号共表达网络与Top-3化学因素（实验审查稿）

**状态**：已完成全量50维候选排名、5折验证、100次Bootstrap、两种子深度消融以及化学来源映射；**当前不能认定模型创新通过验证，也不能将所列化合物解释为因果因素**。正式提交前需要人工化学合理性复核。

## 1. 赛题对应关系与数据来源

- 官方`1.csv`250款啤酒，231个化学/理化指标，真实缺失73个。
- 官方`2.csv`231×231相关矩阵。与`1.csv`逐列位置一致，实测是Spearman；随机重算最大绝对差`5.55e-16`。不能沿用题面“Pearson”。
- 官方`4.csv`50个感官目标（中心化/标准化连续量），本问以它们为监督目标，**没有使用**原论文原始逐品评员0–6评分或官方`8.xlsx`自带的GBM特征重要性进行训练与选特征。
- 主结果`q2_top3_50x3.csv`有50×3=150行，来自218项化学分析候选；排除13个颜色、pH、苦味仪器值、混合物池和计算总量等，不将它们冒充单一化合物。218项中仍包括如铁、乙醇等化学指标，论文标题宜表述为“关键化学因素”。
- `8.xlsx`的`Sensory thresholds`表仅为最终结果附上英文名、来源、单位及原文阈值。原表的阈值未作有效性推断，不混合不同尺度的化学浓度。

## 2. 方法与动机

### 2.1 有符号相关图

保留Spearman符号，单节点分别筛选正、负相关边前6条，候选需满足`|rho|≥0.38`，合并为对称无向图。

实测951条边（正823、负128），Louvain得到20个社区，模块度0.6642；这是预设阈值的结果。阈值0.30/0.45/0.50得到1359/679/496条边及12/35/61个社区，证明社区数量对阈值较敏感，不能把20视为稳固化学事实。

### 2.2 Top-3排名

对每个目标分别计算：(a)总体Spearman；(b)风格内均值残差Spearman；(c)ElasticNet系数；(d)Ridge系数。各证据转为同维百分位秩后，以0.27/0.18/0.35/0.20固定加权。贪心选三个化学候选，对同社区且高度共线的候选施加最多0.12的冗余扣分。

这些权重是本轮预设建模假设，**没有外部数据验证其最优性**。不应称为理论上最优的综合权重。Top-3仅代表观察性关联。

### 2.3 预测价值与稳定性

使用前一阶段Q1冻结的分风格5折（每折200训练、50验证）。选择化学指标、归一化及回归拟合全部只在训练折完成；用相同Ridge训练折只拟合被选中的3项，在测试折评估标准化感官值MAE。完整231特征ExtraTrees为预测上界性参考，不能据此证明任何单项具有因果效应。

100次按风格分层Bootstrap，每次重估Spearman图、拟合所有证据、重新筛选完整Top-3。稳定性为两次重抽样Top-3集合的Jaccard平均数，及最终3项在100次中入选Top-3的频率。对照使用相同重抽样的纯Spearman Top-3。

### 2.4 图神经模型消融

输入为折内稳健缩放后的231项化学特征，基于训练折的Spearman建正负两种邻接，利用`x @ (A_pos-A_neg)`作为消息传递，再以两个同规模特征通路映射到50个输出。用随机重排有符号邻接、单位邻接作为参数量不变的对照，固定130 epoch、相同种子和训练配置。折外样本未参与图生成、早停或归一化。使用两种子（2026、2027），不会根据测试集挑选种子。

## 3. 实测结果

### 3.1 化学Top-3的5折预测价值（50维MAE，越低越好）

| 3特征选择方法 | MAE |
|---|---:|
| 随机3项化学指标 | 0.41127 |
| Ridge系数Top-3 | 0.39139 |
| Spearman Top-3 | 0.38009 |
| 多证据融合Top-3 | **0.37729** |
| 全231特征Ridge | 0.37681 |
| 全231特征ExtraTrees | **0.34018** |

融合相对Spearman的0.00280 MAE改善，在250款啤酒固定折外预测上的配对Bootstrap 95%区间为`[-0.00191,0.00720]`，跨越0。因此**不能声称融合显著优于Spearman**。因为筛选方案是在同一批数据上探索，区间还未完全覆盖模型选择的乐观偏差。

### 3.2 Top-3稳定性

| 指标，跨50个感官维度平均 | 多证据融合 | Spearman |
|---|---:|---:|
| 两次Bootstrap Top-3的Jaccard | 0.21085 | **0.26568** |
| 最终Top-3在Bootstrap中平均入选率 | 0.4286 | **0.4986** |

**主要负结果**：融合方法没有提高稳定性，反而更低。50个维度中只有16个维度的Jaccard高于Spearman。不能将其作为本问的稳定性创新成功证据。完整每维表在`results/q2_stability_vs_spearman.csv`。

### 3.3 深度模型消融

按两种子各自独立的五折平均：真实有符号图0.41083、随机重排图0.41132、无图0.41263。优势很小。将两种子模型的预测先平均再计算MAE，则真实图0.39205、随机重排图0.38914、无图0.38988；从这个对照看真实图反而略差，固定折外配对Bootstrap未证实增益（真实图相对无图改善区间`[-0.00662,0.00215]`）。

**结论**：图结构与稀疏深度模型在当前设置下没有通过增益检验，不应在论文中描述为已经证实的创新。深度模型也不能作为预测精度最高的方法。

## 4. 化学合理性核验

- 直接关系较明确的案例：酒精感官`alcohol`的Top-1为`ethanol..v.v.`（入选100/100次，整体Spearman约0.817）；`X4vg`的Top-1为`X4VG`（入选100/100次，Spearman约0.473）；`lactic`的Top-1为乳酸测量项。
- 需要谨慎的案例：`diacetyl`感官维度的直接测量项`X2.3.butanedione`与目标Spearman仅-0.098，绝对相关排名85；`dms`的DMS为0.088，排名90；`t2n`的(E)-2-nonenal约-0.151，排名19。**这不意味着直接化合物不存在作用**；说明以250款啤酒的感官总体数据计算出的稳定关联不足，可能涉及风格、检测限、复合气味及品评噪声，仍需查证。
- 风格控制后相关正负方向信息已输出，方向不一致的候选不能轻易断言适用于所有风格。
- `4VG`在某些小麦啤酒风格中有积极的丁香风味特征，不能一概写成坏味。论文只写观察性关联，不使用“导致”“驱动”等无干预支持的因果词。
- `q2_top3_50x3_with_chemical_meta.csv`包含每项化合物的参考来源、气味阈值字段，但这些是原数据的说明元数据，不能替代逐条化学文献支持。部分文献归因需要进一步查证才能进入终稿。
