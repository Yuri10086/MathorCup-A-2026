## 2. P0-1：四格表的 ②③ 贴反了，"2.7 倍差来自训练目标"是反的

### 2.1 用你自己的四个数就能证明

把四格排成 2×2（行 = 训练目标用谁的均值，列 = 分母用谁的均值），做标准的主效应分解：

| | 分母 = 真 g | 分母 = 训练折 ĝ |
|---|---|---|
| **目标 = 真 g** | ① `+0.0025` | ② `+0.0045` |
| **目标 = 训练折 ĝ** | ③ `+0.0242` | ④ `+0.0252` |

**按 v11 现有标签分解**（这正是文档的归因）：
- 分母主效应 `+0.0015`
- **目标居中主效应 `+0.0212`** ← 文档说"2.7 倍差来自训练目标"，就是这个数
- 交互 `−0.0010`

**把 ②③ 对调后分解**：
- **分母主效应 `+0.0212`**
- 目标居中主效应 `+0.0015`
- 交互 `−0.0010`

**同一组数字，只换两个格子的标签，"谁是主因"就整个翻过来，而且是 14 倍对 1 倍。** 这说明这个归因完全由标签决定，不由数据决定——所以标签必须用独立计算来定，不能用"哪个数大就归给哪个因素"。

### 2.2 我的独立实测定标签

用同一套算式（`T = Y − g_ctr`；在 `T` 上 fit；`resid = T − P`；`SSE = Σresid²`；`SSW = Σ(Y − g_den)²`；`R² = 1 − SSE/SSW`），四格全跑（`r12_c.py`）：

| | 分母 = 真 g | 分母 = 训练折 ĝ | 目标主效应 |
|---|---|---|---|
| **目标 = 真 g** | ① `+0.0025`（21/50） | ② **`+0.0219`（35/50）** | |
| **目标 = 训练折 ĝ** | ③ **`+0.0059`（24/50）** | ④ `+0.0254`（38/50） | |
| **分母主效应** | | | |

- **分母主效应 `+0.0195`**
- **目标主效应 `+0.0034`**
- **交互 `+0.0001`**（几乎为零）

**结论：R² 的高低由分母决定（5.6 倍），目标居中只贡献 0.0034；两者无交互。**

机制（这也是 v7 那条 P0 的原话，只是当时是聚合口径、这次是逐维口径）：

> 分母写 `Σ(y − ĝ_train)²` 时，**训练行上的 ĝ 是由这些行自己算出来的（in-sample）**，`Σ(y−ĝ)²` 被压小；而 `Σ(y−g_true)²` 里的 `g` 不依赖单行。分母一小，`R² = 1 − SSE/SSW` 就整体抬高。**这是分母的 in-sample 偏差，与"目标怎么居中"无关。**

**v7 已经因为这个分母被评审过一次（当时是"高估 23.4%、R² 凭空抬高 0.23"），v11 在四格表里又踩了同一个机理，只是量级小到 0.02，很容易被当成"实现差异"放过。**

### 2.3 直接后果（三处）

1. **那句机制解释要整句重写**（"用训练折均值居中（③④）等于把目标也做了一次带噪的风格均值基线……R² 系统性抬高"）——主因写错了对象。
2. **"③ 作乐观上界"要改成"④"**：③ 现在是 `+0.0059`，不是 `+0.0242`。真正的最乐观是 ④ `+0.0254`。
3. **②④ 建议整格删除**，不进入区间。理由不是"它们数值大"，而是**分母含 in-sample 偏差、与 ①③ 不可比**。删掉后剩下的可比口径是 ①`+0.0025`、③`+0.0059`、⑤`+0.0040`（见 P0-2）——**三者区间是 `+0.0025 ~ +0.0059`，不是 `+0.002 ~ +0.025`**。

> **这一条与"结论要不要改"无关**：`(B)` 的 `+0.027（32/50）` 仍然提供上端，摘要的"约 0.3%–2.5%"可以不动。要改的是"`0.025` 从哪来"——它现在挂在不可比的分母上。

## 3. P0-2：① 不是部署口径；真正可部署的是第 ⑤ 格（`+0.0040`）

### 3.1 问题

文档 §2.3 那张对照表写着：

| | (B) 真固定效应 | (C) 层内偏差回归 |
|---|---|---|
| 居中用的 `g` | 测试集的真实风格标签 | 训练折估计的 `ĝ`（**部署时才有**） |
| 是否可部署 | ❌ oracle | ✅ 可部署 |

**这句对 ③④ 不成立。** `ĝ` 是"按风格分组算的组均值"，要用它居中，仍然必须先知道这个样品属于哪个风格。部署时不知道风格 → `T = Y − ĝ_style` 这一行根本写不出来。**①②③④ 四格全部需要 `tasting_category_fine`。**

这一点和 v6→v8 那轮判过的问题完全同型：v8 曾把"(B) 用测试时真实风格标签"标成 oracle、把 (C) 标成可部署，v9 已经指出过一次；v11 换成了四格编号，同一个错误又出现一次。

### 3.2 补跑第 ⑤ 格（真正可部署）

`ŝ = Logistic(X)` 的 **OOF 预测风格**（acc 0.484，与 §2.3 第四步同一个数），居中用训练折里 `ŝ` 对应风格的均值（未见风格回退全体均值），分母用真 `g`：

| 格 | 居中 | 需要真实风格标签？ | 逐维均值 | 为正 |
|---|---|---|---|---|
| ① | 真 `g` | **需要**（oracle） | `+0.0025` | 21/50 |
| ③ | 训练折 `ĝ` | **需要** | `+0.0059` | 24/50 |
| ⑤ | **`ĝ_ŝ`（OOF 预测风格）** | **不需要** | **`+0.0040`** | **24/50** |

**三个数的区间是 `+0.0025 ~ +0.0059`，⑤ 正好落在中间。** 这是本轮最有价值的一条正面结果：

### 3.3 建议的表述

## 8. P1-5：断言 #24 检查的是手写常量，不是计算

```python
TOP1_BY_DIM = {
    "bitternes": {"bitterness": 0.12, "iron": 0.62, "other": 0.26},   # 7/60、37/60、16/60
    "X4vg":      {"X4VG": 1.00},
    ...
}
for dim, fr in TOP1_BY_DIM.items():
    assert sum(fr.values()) <= 1 + 1e-9
```

**这个断言拦不住任何东西。** 它检查的是一张手写字典的内部一致性——表和断言可以一起错（这正是 v10 断言 #23 的病，只是这次换成了一张字典而不是一个数）。而且 `0.12 + 0.62 + 0.26 = 1.00` 恰好通过，`7/60 + 37/60 + 16/60` 也恰好通过，两种写法都过——它连"四舍五入是否吃掉一位"都测不出来。

**正确写法**：从 bootstrap 的原始计数算，让频率由计数除出来。

```python
TOP1_COUNTS = {"bitternes": {"bitterness": 7, "iron": 37, "other": 16}}   # 原始计数
B = 60
for dim, cnt in TOP1_COUNTS.items():
    assert sum(cnt.values()) == B, f"{dim} 的计数和 {sum(cnt.values())} != B={B}"
    fr = {k: v / B for k, v in cnt.items()}
    assert abs(sum(fr.values()) - 1) < 1e-12
```

这样"频率和 = 1"是被**计数约束**保证的，不是被一个凑出来的字典保证的。**同时它能拦住 v9–v10 那种错：谁把 0.89 写进去，`sum(cnt) != 60` 立刻红。**

## 10. 可直接替换的正文（四段）

### 10.1 §2.3 四格表（整表替换）

> **层内偏差回归的四格扫掠**（`T = Y − g_ctr`；在 `T` 上 fit；`resid = T − P`；`SSE = Σresid²`；`SSW = Σ(Y − g_den)²`；`R² = 1 − SSE/SSW`）：
>
> | 格 | 训练目标去谁的均值 | 分母 `SSW` 用谁的均值 | 逐维均值 | 为正 | 分母是否可比 |
> |---|---|---|---|---|---|
> | **①** | 真实全样本 `g` | **真实全样本 `g`** | **+0.0025** | 21/50 | ✅ 基准 |
> | **③** | 训练折 `ĝ` | **真实全样本 `g`** | **+0.0059** | 24/50 | ✅ 可比 |
> | ② | 真实全样本 `g` | 训练折 `ĝ`（in-sample） | +0.0219 | 35/50 | ❌ 不可比 |
> | ④ | 训练折 `ĝ` | 训练折 `ĝ`（in-sample） | +0.0254 | 38/50 | ❌ 不可比 |
> | **⑤** | **`ĝ_ŝ`（OOF 预测风格）** | **真实全样本 `g`** | **+0.0040** | 24/50 | ✅ 且**可部署** |
>
> **为什么 ②④ 不可比**：`ĝ` 在训练行上是由这些行自己算出来的（in-sample），`Σ(y−ĝ)²` 被压小；分母一小，`R² = 1 − SSE/SSW` 就整体抬高。**这是分母偏差，与"目标怎么居中"无关。** 用 2×2 主效应分解可验证：**分母主效应 `+0.0195`、目标主效应 `+0.0034`、交互 `+0.0001`**——分母的影响是目标的 5.6 倍，且两者几乎无交互。因此 **②④ 只作机制说明，不进区间**。
>
> **为什么 ⑤ 是唯一的部署口径**：`ĝ` 与 `g` 都需要知道样品的风格标签；只有用 `ŝ = Logistic(X)` 的 OOF 预测风格、再取 `ĝ_ŝ`，才能在不知道风格时算出来。⑤ 的 `+0.0040`（acc 0.484）与 ① 的 `+0.0025` 同量级，说明**风格标签错一半也不会再损失什么**——这正是"层内信号本来就极弱"的直接证据。

### 10.2 §2.3 结论句（三句替换）

> **① 风格之内，化合物对感官仍有可检出的增量，但只有约 0.3%–2.5%：诊断口径（已知风格的 oracle 居中）真固定效应 `+0.027`、32/50 维为正；层内偏差回归在三种居中方式下为 `+0.0025`（真实风格）、`+0.0059`（训练折均值）、`+0.0040`（**OOF 预测风格，唯一可部署**）、21–24/50 维为正。**
> **② 这个增量小到绝对精度反而下降**：`chem+style` 的层内预测 **−0.090**，不如直接报风格均值 —— **它有信息，但不够做个体化反解。**
> **③ 因此"风格内不存在可学的映射"必须撤回**；能支持的最强结论是"**个体层面的映射弱到没有工程价值**"。

### 10.3 §5.4 Top-1 那一句（替换四数并列）

> **四个数必须并列报，且分母统一**：Top-3 命中率 `7/11 = 0.636（47.9×）`、Top-3 平均入选频率 `6.00/11 = 0.545（41.1×）`、**Top-1 稳定命中 `3/10 = 0.300（67.8×）`**、**Top-1 平均频率 `2.98/10 = 0.298（67.4×）`**。

## 14. 本轮元教训（接在附录 F 后面）

前五轮的形态是"**分项与表内数值不自洽**"（0.462 / 0.90 / 0.636 / 82.2 / 0.89）。v11 把这三条防线（#20/#24/#25）都建起来了，**这一轮没有再犯那个错**——四个数、七个瓶数、27/14/9 全部逐位复现。

**这一轮犯的是下一个形态：标签与算式不自洽。**

四格表的四个数字都对，但 ②③ 的标签贴反了，于是"哪个因素是主因"整个反了。这类错误**比数值错更难发现**，因为：
1. 每个数字单独看都复现得出；
2. 结论的量级（0.3%–2.5%）不变，所以改与不改都不影响摘要；
3. 只有做一次**因子分解**（而不是逐个核对）才会暴露。

所以附录 F 那句"先问它是被算出来的还是被定义出来的"要再加半句：

> **"再问：这个数是挂在哪个标签下面的？把标签换一次，结论会不会翻？"**
> —— 数值可复现 ≠ 归因正确。四格的四个数都对，标签一换，主因从"目标"变成"分母"，倍数从 1 倍变成 14 倍。
