## 2. 必须改的三处

### 2.1 0–6 分级表：按现在的写法，85% 的分是 0（最危险）

v3 §4.1.1 的锚点是"`0 ↔ 0`、`6 ↔ 6`"，依据是"`max = 6.172` 与上限 6 几乎重合，暗示原量纲未做中心化"。**这个依据是错的**，实测：

```
4.csv 逐维 mean 中位 = +0.009        |sd − 1| 中位 = 0.447
负值占比 = 60.9%                    恰为 0 的占比 = 0.00%
逐维 max 中位 = 2.26（最小 1.35）   逐维 min 中位 = −0.71（50/50 维都含负值）
值 > 5 的占比 = 0.0%
6.172 来自 clove 一维（该维 sd 0.56 → z ≈ 11，是离群点，不是刻度）
```

**4.csv 是逐维标准化后的面板均值**，均值就在 0 附近。所以：

| 映射方式 | 0 分占比 | 6 分占比 | 单维等级数（中位） | 平均等级 |
|---|---|---|---|---|
| **(a) v3 的截断取整** | **84.6%** | **0.0%** | **3** | **0.18** |
| (b) 逐维 min-max → 0…6 | 24.4% | 0.8% | 7 | 1.61 |
| (c) 分位数 7 箱 | 14.4% | 14.4% | 7 | 3.00 |

把这张表交给评委，等于告诉对方"我没有认真做分级"。

**附带一个自伤点**：§4.1.1 写"若三种变体的 κ > 0.7 则说明分级结论稳健"。实测 κ(a,c) = **0.086**、κ(b,c) = **0.507**、κ(a,b) = 0.307——**没有一对能到 0.7**。这句承诺会当场失败，必须删掉，改成把 κ 当作"局限"报告，而不是验收标准。

**正确写法（三步）**：

1. **声明** 4.csv = 逐维标准化后的感官面板均值（均值≈0、sd≈1、60.9% 为负），因此原 0–6 原始分**不可精确还原**；
2. **表 B 用逐维 min-max → [0,6] 取整**（保住 7 个等级、保住尺度两端的可达性），并在表前写明"假设面板均值的观测极值对应评分卡两端"；
3. **论证结论不受映射影响**：任何单调映射都保持 Spearman 秩不变 → 本文所有排序类结论（可预测性谱、Top-3、迁移前后比较）与映射无关，只有等级标签变。这比许诺 κ>0.7 强得多，因为它**可证明**。

**还有一个交付口径问题**：`summary` 的 `Beer` 列是 1…12，`3.xlsx` 是 `beer_1`…`beer_12` 共 12 张评分卡 → **Q1 的交付表是 12 行 × 50 列，不是 250 行**。v3 通篇按 250×50 写，没有一句说明这 12 个样品是谁、与 4.csv 的 250 行如何对应。这是评委翻第一页就会找的东西，必须补一句显式假设（并说明"12 个样品的身份未知，按 Beer# 输出"）。

### 2.2 "60% 是风格介导"在算术上不可能

v3 §2.3 写："化合物信号约 60% 是风格介导的（0.195 → 0.077 层内）"。这句话用两个不同分母的 R² 相除得到，不是方差分解。实测方差预算：

```
1 − SSW/SST（风格间方差占比）：均值 0.316   中位 0.261   最大 0.756
SST 里能被"风格"承载的上限就是 31.6%
```

而 0.195 → 0.077 隐含的 between 占比是 `1 − (1−0.195)/(1−0.077) = 0.128`——**与实测 0.316 矛盾**（差 2.5 倍）。同协议、裁剪后的实测：

| 模型 | 平均 R² | 中位 R² | 层内 R²（1−SSE/SSW） |
|---|---|---|---|
| 化合物（RidgeCV） | **0.184** | 0.178 | **−0.202** |
| 纯风格（OOF 组均值） | 0.153 | 0.074 | −0.238 |
| 差值 | **+0.031** | — | +0.036 |

化合物只在 **33/50** 维胜过纯风格，平均增量 **+0.032**；**层内 R² 是负的**（比直接用风格均值预测还差）。

**正确表述（也是全文最强的结论）**：
> **全部可解释方差都发生在风格之间；风格内部，化合物不提供任何可用的感官信息。**

这句话把你现在的三个"风险点"一次性变成"证据"（见 §3）。

### 2.3 P0-1 第三次归因错：真正的开关是 2 行高杠杆样本

v3 用 α=1 的 −684 与 α=1e3 的 −0.579 说明"α 是主开关、裁剪只是输出校准"。方向对，但**漏掉了造成这一切的原因**：

```
acetic 一维：R² = −7.6
  样本 73（Kriek，该行 max|z| = 15.8）：y = −0.28，pred = +32.64
  样本 71（Faro， 该行 max|z| = 15.8）：y = −0.26，pred = +6.45
  其余 248 行的 5 折 R² 都在 +0.46 ~ +0.49
```

样本 73/71 正是你自己在 §6.5 标注的 `Faro(3)` / `Brut(4)` 长尾风格。**两行样本把 50 维的平均 R² 拉到负几百**：α=1 时均值是 −684，中位数只有 −412，最差一维 −5848——均值完全由尾部决定，这张表量的不是"模型好不好"，而是"最差的那一维爆到多少"。

**决定性实验**：逐列 winsorize 到 [1%, 99%] 后

| α | 原始 X：不裁剪 / 裁剪 | winsorize 后：不裁剪 / 裁剪 |
|---|---|---|
| 1 | −684.183 / −1.555 | −2.250 / −1.328 |
| 100 | −9.804 / +0.108 | +0.149 / +0.158 |
| **1e3** | −0.579 / +0.182 | **+0.213 / +0.213（Δ = 0）** |
| 1e4 | +0.060 / +0.071 | +0.078 / +0.078 |

**所以准确的说法是两件事，不是一件**：

- **α 的效应是真欠正则**（α=1 即便 winsorize 后仍是 −2.25）；
- **裁剪的效应 100% 来自那两行**（winsorize 后 α≥1e3 时裁剪前后完全相同，Δ=0）。

论文里应当写成："R² 的均值对 2/250 个高杠杆样本极度敏感（α=1 时均值 −684、中位 −412）；对 X 做 1–99% winsorize 后，α≥1e3 的裁剪效应为零。**因此全文报中位 R² 与逐维 CI，均值仅作参考**。"——这比"α 是主开关"更准确，也顺手解释了为什么 §2.2 那张表的中位数一直是稳的（−412 → +0.162 才是真信号）。

**另外，§2.2 那段反驳是事实错误，建议整段删掉**：

> v3 原文："外部评审曾报 `RidgeCV` 不裁剪 = +0.217，本人在 5 组 α 网格上均复现不出……实测其差异来自 X 中是否含风格 one-hot。"

我那个 +0.217 **用的就是纯化合物、无风格 one-hot**。差异来自 **"逐维 RidgeCV"（你的表）vs "多输出 RidgeCV"（我的数，一个 α 管 50 维）**，两者都合法。实测：

```
逐维 RidgeCV（你的口径）      不裁剪 −2.67 ~ −2.88，裁剪 +0.195（48/50）
多输出 RidgeCV（我的口径）    不裁剪 +0.217 ~ +0.222，裁剪 +0.219（49/50）
```

把"复现不出"写进论文，等于把一个可复现的协议差异写成对方算错。评委只要试 25 行代码就会看到 +0.22。改成一句中性的话即可："逐维与多输出两种 α 选择协议给出的均值相差 2.9，说明该统计量对协议敏感，故以中位数为准。"

## 3. 你已经有比"可预测性谱"更强的结论（这是最该做的创新升级）

v3 的主线是"化合物→感官的映射强度是一个可预测、可归因的谱"。但 §2.2 的数据说的是另一件事：

| 环节 | 实测 | 含义 |
|---|---|---|
| 化合物 → 风格（22 类） | 准确率 **0.508**（多数类 0.124） | 化学谱**很会认风格** |
| 风格 → 感官 | η² 均值 **0.316** | 风格能解释 1/3 的感官方差 |
| 化合物 → 感官 | R² **0.184**（纯风格 0.153） | 增量只有 **+0.032** |
| 风格内 化合物 → 感官 | R² **−0.202** | **没有信息** |

**改成两步链的叙事**：
> 化合物测的是"这是哪一类啤酒"，感官评的是"这一类该有的样子"。两者的一致性来自风格，不来自个体配方。所谓"风味指纹"，本质是**风格指纹**。

这条改法有三个立刻可兑现的红利：

1. **`co2` 的 Top-3 不再是"风险点"**。v3 §5.4 把 `co2 → ethyl_octanoate/kcalperc` 写成"与 CO₂ 无直接化学关系，需提前准备答辩"。在两步链下这就是**规律的样例**：所有 Top-3 都应是风格标记物。§5.4 从"防御"变成"机制证据"。
2. **Q2 必须加显著性门控（否则会翻车）**。实测 `dms` 的 Top-3 是 `color.EBC. / protein.g.L. / SO2.mg.L.`，而 `dms` 的 R² = **0.004**——这三个名字会被当成"关键化合物"写进论文，任何一个懂啤酒的评委都会当场指出它仨跟 DMS 无关。规则改为：**逐维 bootstrap CI 不含 0 才报 Top-3，否则报"不可归因"**。50 维 × 3 = 150 条里预计只有 ~70 条站得住，删掉一半反而更强。
3. **Q3 的定位更硬**。既然风格内没有可学的映射，就只做"风格条件生成 + 风格典型谱"，明确不承诺"个体化感官目标向量"。这比"只对 T1/T2 做引导"更彻底，也堵住了 Q3 最容易被问穿的点（"你凭什么说这个配方能到这个感官目标"）。

**代价**：v3 的"可预测性谱贯穿三问"要改写成"**风格介导的可预测性**贯穿三问"，§2.2 的层计数从主轴降为描述（这本来就是 M2 的结论）。

## 7. 总体判断

**数据层（第 2 章）：可以定稿。** 量纲三分、名字桥、派生列、地板、位置对齐——这五件事做到了别人做不到的细度，是这份方案真正的护城河。

**解释层（第 3 章）：第三次栽在同一张 R² 表上。** 从 v1 的"裁剪救了 R²"，到 v2 的"裁剪是假象"，到 v3 的"α 是主开关"，每次都在给同一张表换解释，而没有质疑这张表本身：**它的均值由 2/250 行决定**。建议 v4 直接删掉均值做头条，改报中位 + CI + 杠杆样本表。这样这张表就再也不会反噬。

**叙事层（第 3–6 章）：差最后一步。** 你已经有"化合物→风格→感官"的全部证据（0.508 / 0.316 / 0.184 / −0.202），但 v3 仍在讲"化合物→感官的谱"，于是 `co2` 的代理变量成了风险、`dms` 的噪声 Top-3 成了结论、"60%" 成了错误。**把这两步写出来，三个问题会立刻从"三个作业"变成"一个论证"，而且比现在的版本更容易拿奖。**
