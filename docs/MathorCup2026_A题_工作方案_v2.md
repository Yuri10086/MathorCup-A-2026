### 1.2 【v2 最重要发现】1.csv 是混合量纲，不是单一 log10

赛题正文说"部分列是原始浓度经对数变换"。**实测发现不只是"部分"，而且至少有三种口径：**

**判定方法（可写进论文，是可复现的硬证据）**：用 `8.xlsx::Calibrated chemical dataset`（250×73）与 1.csv 逐列比对，检验 `10**x == calibrated` 还是 `x == calibrated`：

```
确认 log10 : 35 列  （相对误差 < 1e-6）  例：DMS / bitterness / pH / acetaldehyde / ethyl_acetate
确认 线性  : 33 列  （相对误差 < 1e-6）  例：X2.3.butanedione(双乙酰) / linalool / geraniol / X.E..2.nonenal
```
> **关键细节**：`CS2` 与 `X4VG` 在标定表中把"低于检出限"记为 **0**，而 1.csv 记为各自的**列专属地板值**（CS2: −2.146292，X4VG: −2.013157）。在标定值 > 0 的样本上，`max|10**x − cal| = 7.1e-10` → **这两列也是 log10**。

对剩余 163 列（不在标定表中），用三条结构性证据推断：
- 含负值 → 必为 log10；
- 有重复最小值（检出限地板）→ 必为 log10；
- 全正、无重复最小值、偏度接近 0 → 判为线性（或已对数化）。

**最终分类：182 列 log10 + 49 列线性。** 49 列线性中：
- **33 列**由标定表硬确认（双乙酰、里那醇、香叶醇、t2n、苯甲醛…）
- **16 列**为"全正、对称、无地板"的列，偏度均值 **−0.20**（对比 33 列确认线性的偏度均值 **+6.36**），说明它们**已经是对数尺度但底数/单位不明**：
  `n.pentanol, X2.methyl.1.butanol, isopentyl.formate, X3.methyl.2.butenal, X3.methyl.2.hexanol, X3.furanmethanol, n.heptanol, ethyl.hex.(3E).enoate, n.octanol, terpinolene, nonan.2.ol, isoborneol, ethyl.benzoate, trans.dihydro.alpha.terpinyl.acetate, X.E..beta.ionone, aroma_hops_sum`

> **处置（论文里必须这样写，且这是加分点）**：对这 16 列**只用于相关/排序/建模，不用于绝对阈值判断**，并在论文中声明。**经核查，8.xlsx 中 43 个有阈值的化合物与 1.csv 的交集共 18 个，与这 16 列零重叠** → **量纲歧义不影响 Q3 的任何阈值结论**。这个"歧义边界"的界定本身就是严谨性的体现。

### 1.3 检出限地板（142 列共享同一地板）

- **142 列**的最小值完全相同 = **−1.817819**（即 10^−1.817819 ≈ **0.0152**）
- 这些列落在地板上的单元格 **6807 个 = 全部 57750（250×231）个化学单元格的 11.79%**
- 在**这 142 列内部**，地板占比是 **19.2%**（6807 / 35500）
- 逐列看，列内占比均值 19.2%，最高 **84.8%**（`X6.methyl.5.hepten.2.one`、`limonene`）
- 另有**列专属地板**：`ethyl_isovalerate` −4.487（33.2%）、`octyl_acetate` −3.455（44.0%）、`isobutyl_acetate` −3.266、`ethyl_2.methyl_butyrate` −3.196（34.0%）、`ethyl_decanoate` −2.976、`CS2` −2.146（**83.6%**）、`X4VG` 97 −2.013（**67.2%**）

**建模含义**：这是**左删失**，不是缺失。必须加 `detected_{j}` 指示变量或做两阶段。**Tobit 在这里是正当的。**

### 1.5 连接口径（写论文时必须交代，否则复现不了）

### 1.6 目标变量：4.csv 到底是什么

- 50 维，每维**唯一值 106–250 个**，单值众数占比**最高仅 4.4%**，**无任何一维单值占比 > 10%**

## 2. 主线科学论点（这是 v2 相对 v1 最大的升级）

### 2.1 一句话 motivation

> **感官是人的判断，化合物是仪器的读数。二者之间的映射强度本身不是常数，而是一个可被预测、可被归因的谱。**
> 三个问题因此成为一条链：**能不能预测（Q1）→ 为什么能/不能（Q2）→ 能不能反过来设计（Q3）。**

### 2.2 可预测性谱（实测，论文核心图）

在 5 折交叉验证、预测裁剪回训练范围的诚实协议下，50 个感官维度的可预测性：

```
平均 R² = +0.195      中位 = +0.162      48/50 维为正      12/50 维 > 0.3
```

**分层（按「化合物相对风格的保留增量」= R²_化合物 − R²_纯风格）**：

| 层 | 判据 | 维度数 | 代表维度 |
|---|---|---|---|
| **T1 化学主导** | 增量 > 0.10 | **4** | `orange`(0.212)、`coriander`(0.167)、`X4vg`(0.129)、`co2`(0.118) |
| **T2 混合** | 0.05 < 增量 ≤ 0.10 | **11** | `A_esters_flower`、`A_malt_all`、`F_esters_ethac`、`sweetness`、`bitternes`、`A_hops_citrus`、`diacetyl`、`F_malt_burn`、`F_malt_grain`、`A_malt_burn`、`F_malt_cara` |
| **T3 风格/事件主导** | 增量 ≤ 0.05 | **35** | 全部缺陷维 + `overall`、`alcohol`、`body`、`lactic`、`acidity`、`acetic` |

### 2.3 为什么会有这个谱（机制，三条实测证据）

**证据 1：可预测性 ≈ 可被风格解释的程度。**
```
pearson(R², R²_纯风格) = +0.925  (p = 9.7e-22)
```
风格单独能解释的方差（η²）中位数 **0.261**；`alcohol` 最高 **0.756**，`coriander` 最低 **0.129**。

**证据 2：跨模型稳健。** Ridge 与 `HistGradientBoosting` 在 15 个分层维度上的**排序 Kendall τ = 0.657** → 这个谱不是某个模型的假象。

**证据 3：层内相关性显著衰减。** 去掉每个风格内部的均值后，中位 Spearman 从 **0.356 → 0.175**（衰减 0.233）。衰减最大的正是 `F_malt_all`(0.417)、`F_malt_cara`(0.397)、`body`(0.388)、`bitternes`(0.365)、`alcohol`(0.356)；衰减最小的是 `coriander`(−0.053，几乎不衰减)、`orange`(0.030)、`A_malt_grain`(0.066)。

> **这条链的论文表述**：化合物信号约 **60% 是风格介导的**（0.195 → 0.077 层内）。**越能被风格预测的维度，越容易被化合物预测**——因为化合物矩阵本身就编码了风格（化合物→风格 22 类分类准确率 **0.508**，多数类基线 0.124）。

### 2.4 对评审 6 个创新点的处置

| 评审建议 | 我的处置 | 理由（实测） |
|---|---|---|
| ① 可预测性谱贯穿三问 | **采纳，升为主论点** | τ=0.657 证明稳健；η² 相关性 0.925 给出机制 |
| ② 检出限地板 → 共检出伪相关 → 三档图 | **降级**，只作清洗有效性证据 | 实测按共删失分箱 Δ\|ρ\|：0–0.1 档 +0.0098，**>0.5 档反而是 −0.0013 / −0.0542**；整体 mean\|ρ\| 0.165 vs 0.158。**地板效应存在但不是伪模块主因，不能当主论点** |
| ③ 零膨胀有序 probit | **否决** | 4.csv 每维唯一值 106–250 个，单值占比 ≤4.4%，**根本没有零膨胀** |
| ④ Q3 逆设计闭环 + OT/Sinkhorn 迁移 | **采纳**（分阶段，见 §5） | 均值位移确实会让方差坍缩 |
| ⑤ GBM 当外部裁判 | **采纳，但仅总体层面** | 该表确为单目标 |
| ⑥ 全文带不确定性区间 | **采纳** | Bootstrap 耗时可接受（§6.3） |

## 4. 问题1：数据缺失条件下的感官评分

### 4.1 交付物规格（严格按 `3.xlsx::summary`）

`summary` 是 **13 行 × 52 列**：`Beer` + **51 个评分列** + `comments`。
**注意别名差异（论文必须给对照表）**：

| `3.xlsx::summary` | `4.csv` | 说明 |
|---|---|---|
| `A_ester_fruity` | `A_esters_fruity` | 单复数不同 |
| `F_ester_fruity` | `F_esters_fruity` | 单复数不同 |
| `4vg` | `X4vg` | 大小写与写法不同 |
| `comments` | （无） | 仅 summary 有 |

> Q1 的表格按 **51 列**布局输出；同时另出一张 **37 维核心区**（Aroma 15 + Flavour 15 + 主体 7）的表，因为这是评委最会看的。

### 4.2 建模方案（按 §2.2 的分层差异化建模）

**T1（4 维，化学主导）——重点投入**
- 主模型：`RidgeCV`（标准化后，α ∈ 1e-1…1e5）+ `HistGradientBoosting`（depth=4, 400 iters, lr=0.05, l2=1.0, leaf=8）
- 特征：化合物 + **检测指示变量**（142 列地板 → 加 `detected`）+ 风格 one-hot
- 目标区间：**Bootstrap B=1000 给 95% 区间**（50 维全跑 25.5 min，可接受）

**T2（11 维，混合）——标准流程**
- 同上，但风格作为强先验，化合物做残差修正

**T3（35 维，风格/事件主导）——诚实降级**
- **明确声明"不可由化合物可靠预测"**，改用**风格条件均值 + 区间**作为预测，并报告层内 R² 为负的事实
- 缺陷维（`dms`/`t2n`/`diacetyl`/`X4vg`/`stale_hops`/`metallic`/`clove`/`barnyard` 中的 8 个）**单列一节说明**：η²_style 中位 0.82，化学信号 R² 多数 < 0.07，层内 R² 转负

### 4.3 评价指标（修正口径）

**必须分组报告**（依据 `Sensory names::DataType`）：

| 组 | 维度数 | 主指标 | 副指标 |
|---|---|---|---|
| categorical | 24 | Spearman ρ（对序关系敏感） | 相邻等级准确率 |
| numeric | 26 | R²（裁剪后） | Spearman ρ |
| **全部** | 50 | 中位 ρ | 分层 R² |

> **明确写进论文**：不报"50 维平均 R²"这种混算指标。评审指出口径错误，采纳。
> 目标值：中位 ρ ≈ 0.35（当前基线 0.356），T1 组 ρ > 0.45，T3 组如实报告接近 0。

### 4.4 缺失数据处理（本题眼，单列一节）

- 1.csv 仅缺 **73 个单元格（0.13%）**，涉及 63 行，单行最多缺 3 个 → **不是主要矛盾**
- 真正的"缺失"是 **11.79% 的左删失**（检出限）→ 用 **Tobit / 两阶段 + 检测指示变量**
- 论文里要把这两件事区分清楚：**MCAR 少量缺失** vs **结构性删失**

## 5. 问题2：化合物–风味分析

### 5.1 共表达图（三档，作为清洗有效性证据）

| 档 | 构造 | 用途 |
|---|---|---|
| G-naive | 1.csv 化合物 Spearman | 基线 |
| G-censor | 只用"双方均检出"的样本对重算相关 | 主图 |
| G-tetra | 对检测指示矩阵做 tetrachoric | 对照 |

**实测结论（必须如实写）**：三档图差异**不大**——mean\|ρ\| 从 0.165 → 0.158；模块纯度从 0.342 → 0.454，伪模块 6 → 7 个。**结论应表述为"删失校正提升了模块的化学家族纯度，但未改变图的整体拓扑"，而不是"naive 图是伪结构"。**

建图参数：\|ρ\| > 0.3 且 FDR < 0.05 连边；Louvain 社区检测（`networkx`，固定 seed）。

### 5.2 Top-3 提取（主判 + 对照，不等权）

| 方法 | 角色 | 说明 |
|---|---|---|
| **M1 Ridge/SHAP** | **主判** | 标准化系数 + permutation importance（repeats=10） |
| **M2 分层/分组 Lasso** | **主判** | 与 M1 互为验证 |
| M3 图先验子集回归 | 对照 | 用 6.csv 的 44 行做先验约束 |
| M4 边际相关 | 对照 | **与 M3 同源，不可与 M3 等权投票** |

**合成规则**：M1/M2 取**交集优先**，不足 3 个用 Borda 补齐；M3/M4 只报一致性（Jaccard）。

### 5.3 稳定性论证（赛题硬要求，必须量化）

- **Bootstrap B=1000**，统计每个化合物进入 Top-3 的**入选频率**；报告 **f ≥ 0.6** 的化合物
- **随机基线**：随机 3 元子集的期望入选频率 = **3/231 ≈ 0.013**（**必须给出，否则 0.6 这个阈值没有意义**）
- **跨方法 Jaccard**：M1 vs M2 的 Top-3 重合度；随机基线 **≈ 0.02**
- **多重比较**：231 个化合物 × 50 维 = 11550 次检验 → 报 FDR 校正后的 q 值
- **耗时预算（实测）**：Ridge 单维 0.031 s → 50 维 1.5 s → **B=1000 全量 25.5 min**（单线程）。HGB 单维 1.84 s → B=1000 需 25.6 h，**排期内跑不完** → HGB 只做一次全样本 permutation importance。

### 5.4 化学合理性论证（用分层结果说话）

- T1 维度的 Top-3 应落在**化学对应家族**：`orange`/`coriander` → 萜类（`limonene` ρ=+0.296、`linalool` +0.177、`terpinolene` +0.208）；`X4vg` → `X4VG`(ρ=+0.473) 主导
- **风险点（提前准备答辩）**：`co2` 的 Top 化合物是 `ethyl_octanoate`(+0.553)、`ethyl_hexanoate`(+0.467)、`kcalperc`(+0.383)，**与 CO₂ 无直接化学关系**，是"发酵程度"的代理变量 → 论文里应表述为**"CO₂ 的可预测性来源于发酵进程的共同驱动，而非直接化学通路"**，并把这个例子作为 T1 层也有"代理信号"的证据，反而增强论证的诚实度
- 模块纯度：用 `Sensory thresholds::origin_paper`（Malt/Yeast/Hops/Others）标注每个化合物的化学家族，算每个模块的家族纯度

## 6. 问题3：风味与"风味指纹"生成

### 6.1 "风味指纹"必须先定义（评审指出概念悬空，采纳）

> **定义**：风味指纹 = 在给定风格 s 下，由生成模型产出的**化合物谱 ĉ** 及其**感官画像 ŷ** 构成的二元组 `(ĉ, ŷ)`，其中 ŷ 只包含 §2.2 中 T1/T2 层的可预测维度，T3 维度以风格条件均值给出并标注为"不可由化合物推断"。

### 6.2 生成模型

- **cVAE**（风格 one-hot 条件），latent 16–32 维，训练 250 样本 → 必须强正则（dropout + KL 权重退火）
- **对照组**：条件 GAN 太不稳（250 样本），**不采用**；改用 **风格条件的高斯 copula / 分位数采样**作为强基线——在这个样本量下它很可能打赢 cVAE，**必须诚实报告**
- 生成后处理：把生成的 log10 列反变换、把线性列保持原样（§1.2 的量纲纪律）

### 6.3 缺陷约束（赛题的坑，必须硬处理）

**阈值来源**（`8.xlsx::Sensory thresholds`，阈值与 `10**x` 同单位比较）：

| 化合物 | 列名 | 阈值 | 单位 | 1.csv 量纲 |
|---|---|---|---|---|
| DMS | `DMS` | 17.25 | µg/L | log10 |
| 双乙酰 | `X2.3.butanedione` | 0.29925 | mg/L | **线性** |
| 4VG | `X4VG` | 0.206333 | mg/L | log10 |
| t2n | `X.E..2.nonenal` | **表中无数值** | — | **线性** |
| stale hops | — | **表中无数值** | — | — |

> **t2n 与 stale hops 必须用文献阈值并声明假设**（t2n 常用 0.11 µg/L），或用 **95 分位操作阈值**。这是赛题的数据缺口，**声明比掩盖得分高**。

**三重保障（不靠拒绝采样碰运气）**：
1. **生成端硬投影**：对每个缺陷化合物，把生成值投影到 `[地板, τ_c]` 区间
2. **margin 指标**：`m_c = −log10(x_c / τ_c)`，`m_c > 0` 即超标；报告生成样本的 `P(m_c > 0)`
3. **报告端诚实**：迁移前后对比的**超标率表**，而不是"平均浓度没变"

### 6.4 跨风格迁移

- **不用均值位移**（会让方差坍缩，评审正确）
- 用 **OT / Sinkhorn** 把源风格的化合物分布搬到目标风格的经验分布
- 目标：`Pils/Lager → Tripel`，约束**缺陷超标率不上升**（逐化合物报告）

### 6.5 长尾风格

22 类中 `Faro`(3)、`Brut`(4) 样本过少 → 合并或只做描述不建生成模型，**论文里明说**。

def load_all(base):
    d1 = pd.read_csv(f"{base}/1.csv", index_col=0)

## 附录 D：量纲判读函数

```python
def classify_scale(d1, chem, cal):
    """返回 {列名: 'log10' | 'linear'}，逻辑见 §1.2"""
    kind = {}
    for c in chem:
        v = d1[c].values.astype(float)
        v = v[np.isfinite(v)]
        if c in cal.columns:
            a, b = d1[c].values.astype(float), cal[c].values.astype(float)
            m = np.isfinite(a) & np.isfinite(b)
            if m.sum() >= 30:
                e_log = np.median(np.abs(10**a[m] - b[m]) / (np.abs(b[m]) + 1e-12))
                e_raw = np.median(np.abs(a[m] - b[m]) / (np.abs(b[m]) + 1e-12))
                if e_log < 1e-6:   kind[c] = "log10";  continue
                if e_raw < 1e-6:   kind[c] = "linear"; continue
                # CS2 / X4VG：标定表把 <LOD 记为 0，只比 >0 的部分
                if (b[m] > 0).sum() >= 30:
                    mm = m & (b > 0)
                    e = np.median(np.abs(10**a[mm] - b[mm]) / b[mm])
                    if e < 1e-6:   kind[c] = "log10";  continue
        # 结构性规则
        if (v < 0).any() or len(np.unique(v)) < len(v):   # 有负值或有重复最小值
            kind[c] = "log10"
        else:
            kind[c] = "linear"
    return kind
```
