### 1.2 【贯穿全程的基础发现】1.csv 是混合量纲，不是单一 log10

赛题正文说"部分列是原始浓度经对数变换"。**实测发现不只是"部分"，而且至少有三种口径：**

**判定方法（可写进论文，是可复现的硬证据）**：用 `8.xlsx::Calibrated chemical dataset`（250×73）与 1.csv 逐列比对，检验 `10**x == calibrated` 还是 `x == calibrated`：

```
确认 log10 : 35 列  （相对误差 < 1e-6）  例：DMS / bitterness / pH / acetaldehyde / ethyl_acetate
确认 线性  : 33 列  （相对误差 < 1e-6）  例：X2.3.butanedione(双乙酰) / linalool / geraniol / X.E..2.nonenal
```
> **关键细节**：`CS2` 与 `X4VG` 在标定表中把"低于检出限"记为 **0**，而 1.csv 记为各自的**列专属地板值**（CS2: −2.146292，X4VG: −2.013157）。在标定值 > 0 的样本上，`max|10**x − cal| = 7.1e-10` → **这两列也是 log10**。

对剩余 **161 列**（231 − 70，不在标定表中），用结构性证据推断，并**分三档输出**：
- 含负值，或存在重复最小值（检出限地板）→ 判 `log10`（**但需过指数护栏**）；
- 全正、无重复最小值、偏度接近 0 → 判 **`log_unknown`**（已对数化，但底数/单位不明，**不等于线性**）；
- 标定表硬证据优先于以上所有规则。

**最终分类（三值，v3 修正）**：

| 类别 | 列数 | 证据 | 用途 |
|---|---|---|---|
| **`log10`** | **182** | 70 列有标定表硬证据，其余经结构性规则 + 护栏 | 可做绝对阈值判断 |
| **`linear`** | **33** | **全部**有标定表硬证据（相对误差 < 1e-6） | 可做绝对阈值判断 |
| **`log_unknown`** | **16** | 全正、对称、无地板；偏度均值 **−0.20**（对比 33 列真线性者偏度均值 **+6.36**）→ 已对数化但底数/单位不明 | **只做相关/排序/建模，禁止绝对阈值判断** |

> **v2 的口径错误（此处修正）**：v2 写"182 log10 + 49 线性"是**把 33 个硬证据线性与 16 个底数不明者混为一谈**。正确的是 **182 + 33 + 16 = 231**。这个区分至关重要——`linear` 可做阈值判断，`log_unknown` 不可。

`log_unknown` 16 列完整清单（v3 实测）：
`X.E..beta.ionone, X2.methyl.1.butanol, X3.furanmethanol, X3.methyl.2.butenal, X3.methyl.2.hexanol, aroma_hops_sum, ethyl.benzoate, ethyl.hex..3E..enoate, isoborneol, isopentyl.formate, n.heptanol, n.octanol, n.pentanol, nonan.2.ol, terpinolene, trans.dihydro.alpha.terpinyl.acetate`

**P0-3 的核心警告（写进论文正文，是本方案的严谨性加分点）**：
结构性回退规则（"含负值或有重复最小值 → log10"）在 70 个可标定列上的实测表现是：

```
precision(log10) = 0.565      recall(log10) = 0.946
真 log10 → 判 log10 35 / 判 linear 2
真 linear → 判 log10 27 / 判 linear 6
```

27 个假阳性**全部是"含 0 或重复 0"的真线性嗅感化合物**：`X2.3.butanedione`、`linalool`、`X.E..2.nonenal`(t2n)、`X1.alpha.terpineol`、`citronellol`、`geraniol`、`Z.nerolidol`、`furfural`、`benzaldehyde`、`ethyl.butyrate`、`ethyl.isobutyrate`、`methylpyrazine`、`amyl.acetate`、`hexyl.acetate`、`benzyl.alcohol`、`phenylacetaldehyde`、`X3Z.hexenol`、`n.hexanol`、`X5.methylfurfural`、`X.E..beta.ocimene`、`X.E.E..2.4.decadienal`、`gamma.nonalactone`、`X.E..beta.damascenone`、`ethyl.pentanoate`、`X2.ethyl.3.methylpyrazine`、`X3.methylbutanal`、`ethyl.nicotinate`。
**恰好把双乙酰与 t2n 误判成 log10**——这两个是 Q3 的核心缺陷物。`X2.3.butanedione` 的 max=**121.73**，若误判为 log10，则 `10**121.73 = 5.4e+121`，阈值判断全错。

→ **处置（护栏的正确形式，v3 实测调好的）**：护栏**必须作用在指数上，不能作用在还原浓度上**。
最初我把护栏写成 `10**max(x) > 1e6` → **误杀 115 个合法 log10 列**（酒花萜类以 µg/L 计，`10**8.3 ≈ 2e8` 完全正常）。
正确的是 **`max(x) > 20` 即降级**（对应浓度 > 1e20 µg/L，物理上不可能）：
```
护栏 exp>20 时：log10 = 182, linear = 33, log_unknown = 16   ← 与无护栏完全一致（真实数据里 0 次触发）
且能捕获误判的双乙酰（其 max=121.73 > 20）                       ← 作为 backstop 有效
```

> **处置（论文里必须这样写，且这是加分点）**：对这 16 列**只用于相关/排序/建模，不用于绝对阈值判断**，并在论文中声明。而**所有 43 个有阈值的化合物都落在 `log10`/`linear` 里（硬证据），零 AMBIG**（见 §1.2.1）→ **Q3 的每一个阈值结论都不受量纲歧义影响**。这个"歧义边界"的界定本身就是严谨性的体现。

## 2. 主线科学论点（这是全文最大的升级）

### 2.1 一句话 motivation

> **感官是人的判断，化合物是仪器的读数。二者之间的映射强度本身不是常数，而是一个可被预测、可被归因的谱。**
> 三个问题因此成为一条链：**能不能预测（Q1）→ 为什么能/不能（Q2）→ 能不能反过来设计（Q3）。**

### 2.2 可预测性谱（实测，论文核心图）

**先立纪律（P0-1 修正，这段必须原样写进论文）**：

> 平均 R² 的符号与量级由 **α 正则化强度**主导，而非由裁剪主导。裁剪（clip 回训练观测范围）是**输出校准**，在 α 得当时其效应中位数恰为 0。

实测证据（50 维、中位填补、`KFold(5, shuffle=True, seed=0)`、`StandardScaler`）：

| 模型 | 不裁剪 平均R² | 裁剪后 平均R² | 裁剪后为正的维数 |
|---|---|---|---|
| `Ridge(α=1)` | −684.18 | **−1.555** | 1/50 |
| `Ridge(α=10)` | −79.12 | −0.410 | — |
| `Ridge(α=100)` | −9.804 | +0.108 | 29/50 |
| `Ridge(α=1e3)` | −0.579 | **+0.182** | **49/50** |
| `Ridge(α=1e4)` | +0.060 | +0.071 | 50/50 |
| `Ridge(α=1e5)` | +0.004 | +0.004 | 30/50 |
| **`RidgeCV`(1e-2…1e4)** | −2.809 | **+0.195** | **48/50** |

**读法**：α=1 时裁剪后仍是 −1.555 → **"裁剪救了 R²"是错的**；α=1e3 时不裁剪就已 +0.182、裁剪几乎不改变（`median|Δ| = 0.000`）→ **α 才是主开关**。
`RidgeCV` 落在 α≈1e3 附近，故不裁剪的 −2.809 与裁剪后的 +0.195 之间的大落差**不是裁剪的功劳**，而是 RidgeCV 逐维选出的 α 方差很大、少数维仍欠正则所致。

> **注**：外部评审曾报"`RidgeCV` 不裁剪 = +0.217"，本人在 5 组 α 网格（1e-1…1e5 / 1e0…1e4 / 1e1…1e4 / 1e2…1e5 / 1e3…1e6）上**均复现不出**（全部 −2.55 ~ −2.81）。实测其差异来自 **X 中是否含风格 one-hot**：`chem+style`(253 列) 不裁剪 **−2.290** / 裁剪 +0.214；`style only`(22 列) 不裁剪 **+0.182**。论文采用可复现的本表口径。

**在 α 合理的诚实协议下，50 个感官维度的可预测性**：

```
平均 R² = +0.195      中位 = +0.162      48/50 维为正      12/50 维 > 0.3      平均 Spearman ρ = 0.395
```

**分层（M2 修正：改为连续谱 + 区间，不做硬分层）**：

不再声称"T1 就是这 4 个维度"。改为给出**连续谱**与**层计数区间**：

| 层 | 判据（增量 = R²_化合物 − R²_纯风格） | 维度数 | 跨 4 个 seed 的稳定性 |
|---|---|---|---|
| **T1 化学主导** | 增量 > 0.10 | **约 4 维（seed 间 3–4）** | **成员不稳**：4 个 seed 下只有 `orange`、`coriander` 每次都入选；`X4vg`/`dms`/`co2`/`F_malt_burn`/`bitternes`/`A_esters_flower` 各只入选 1–2 次 |
| **T2 混合** | 0.05 < 增量 ≤ 0.10 | 8–10 维 | 部分换人 |
| **T3 风格/事件主导** | 增量 ≤ 0.05 | 36–38 维 | 稳定（含全部缺陷维） |

**跨 seed 稳定性实测（4 seed × 50 维）**：
- 每维增量 incr 的**跨 seed 标准差：中位 0.0666、p90 0.0708**（不是评审说的 0.017——本口径是"跨 seed"，评审的 0.017 应是 fold 间方差）
- **22/50 维在 4 个 seed 下会换层** → **任何"某维度属于某层"的硬断言都不成立**
- **稳定的是计数与平均 R² 排序**：平均 R² 排序的跨 seed Spearman = **0.923 / 0.956 / 1.000 / 0.943**
- **不稳的是增量排序**：incr 的跨 seed Spearman 仅 **0.568 – 0.697**

> **因此论文主轴必须用「平均 R² 谱」（稳），分层只作描述性辅助（不稳）**，且每维都要报 **Bootstrap 95% CI**。摘要里写"约 5±2 维呈现化学主导"这类带区间的表述，不写确定数字。

### 2.3 为什么会有这个谱（机制，三条实测证据）

**证据 1：可预测性 ≈ 可被风格解释的程度。**
```
pearson(R², R²_纯风格) = +0.925  (p = 9.7e-22)
```
风格单独能解释的方差（η²）中位数 **0.261**；`alcohol` 最高 **0.756**，`coriander` 最低 **0.129**。

**证据 2：跨模型稳健。** Ridge 与 `HistGradientBoosting` 在 15 个分层维度上的**排序 Kendall τ = 0.657** → 这个谱不是某个模型的假象。

**证据 3：层内相关性显著衰减。** 去掉每个风格内部的均值后，中位 Spearman 从 **0.356 → 0.175**（衰减 0.233）。衰减最大的正是 `F_malt_all`(0.417)、`F_malt_cara`(0.397)、`body`(0.388)、`bitternes`(0.365)、`alcohol`(0.356)；衰减最小的是 `coriander`(−0.053，几乎不衰减)、`orange`(0.030)、`A_malt_grain`(0.066)。

> **这条链的论文表述**：化合物信号约 **60% 是风格介导的**（0.195 → 0.077 层内）。**越能被风格预测的维度，越容易被化合物预测**——因为化合物矩阵本身就编码了风格（化合物→风格 22 类分类准确率 **0.508**，多数类基线 0.124）。

## 6. 问题3：风味与"风味指纹"生成

### 6.1 "风味指纹"必须先定义（评审指出概念悬空，采纳）

> **定义**：风味指纹 = 在给定风格 s 下，由生成模型产出的**化合物谱 ĉ** 及其**感官画像 ŷ** 构成的二元组 `(ĉ, ŷ)`，其中 ŷ 只包含 §2.2 中 T1/T2 层的可预测维度，T3 维度以风格条件均值给出并标注为"不可由化合物推断"。

### 6.2 生成模型

- **cVAE**（风格 one-hot 条件），latent 16–32 维，训练 250 样本 → 必须强正则（dropout + KL 权重退火）
- **对照组**：条件 GAN 太不稳（250 样本），**不采用**；改用 **风格条件的高斯 copula / 分位数采样**作为强基线——在这个样本量下它很可能打赢 cVAE，**必须诚实报告**
- 生成后处理：把生成的 log10 列反变换、把线性列保持原样（§1.2 的量纲纪律）

### 6.3 缺陷约束（赛题的坑，必须硬处理）

**阈值来源**（`8.xlsx::Sensory thresholds`，阈值与 `10**x` 同单位比较）：

| 化合物 | 列名 | 阈值 | 单位 | 1.csv 量纲 |
|---|---|---|---|---|
| DMS | `DMS` | 17.25 | µg/L | log10 |
| 双乙酰 | `X2.3.butanedione` | 0.29925 | mg/L | **线性** |
| 4VG | `X4VG` | 0.206333 | mg/L | log10 |
| t2n | `X.E..2.nonenal` | **表中无数值** | — | **线性** |
| stale hops | — | **表中无数值** | — | — |

> **t2n 与 stale hops 必须用文献阈值并声明假设**（t2n 常用 0.11 µg/L），或用 **95 分位操作阈值**。这是赛题的数据缺口，**声明比掩盖得分高**。

**三重保障（不靠拒绝采样碰运气）**：
1. **生成端硬投影**：对每个缺陷化合物，把生成值投影到 `[地板, τ_c]` 区间
2. **margin 指标**：`m_c = −log10(x_c / τ_c)`，`m_c > 0` 即超标；报告生成样本的 `P(m_c > 0)`
3. **报告端诚实**：迁移前后对比的**超标率表**，而不是"平均浓度没变"

### 6.4 跨风格迁移

- **不用均值位移**（会让方差坍缩，评审正确）
- 用 **OT / Sinkhorn** 把源风格的化合物分布搬到目标风格的经验分布
- 目标：`Pils/Lager → Tripel`，约束**缺陷超标率不上升**（逐化合物报告）

### 6.5 长尾风格

22 类中 `Faro`(3)、`Brut`(4) 样本过少 → 合并或只做描述不建生成模型，**论文里明说**。

```python
import pandas as pd, numpy as np

DERIVED = {"esters_sum", "acids_sum", "aroma_hops_sum", "sulfur_sum", "kcalperc"}

def load_all(base):
    d1  = pd.read_csv(f"{base}/1.csv", index_col=0)
    d2  = pd.read_csv(f"{base}/2.csv", index_col=0)
    d4  = pd.read_csv(f"{base}/4.csv", index_col=0)
    d6  = pd.read_csv(f"{base}/6.csv", index_col=0)
    d7  = pd.read_csv(f"{base}/7.csv", index_col=0)
    cal = pd.read_excel(f"{base}/8.xlsx", sheet_name="Calibrated chemical dataset")
    th  = pd.read_excel(f"{base}/8.xlsx", sheet_name="Sensory thresholds")

    chem = [c for c in d1.columns if c not in ("beer_id", "tasting_category_fine")]
    sen  = [c for c in d4.columns if c not in ("beer_id", "tasting_category_fine")]

    # ---- 1 形状 ----
    assert d1.shape == (250, 233), d1.shape
    assert d4.shape == (250, 52),  d4.shape
    assert d7.shape == (250, 188), d7.shape

    # ---- 2 2.csv 就是 Spearman，且按位置对齐 ----
    assert np.nanmax(np.abs(d2.values - d1[chem].corr("spearman").values)) < 1e-12

    # ---- 3 风格标签逐行一致（4.csv 的 beer_id 已被舍入，禁止 id join）----
    assert (d1["tasting_category_fine"].values == d4["tasting_category_fine"].values).all()

    # ---- 4 名字桥分层断言（P0-2）----
    assert len(set(chem) & set(th["field_name_R"])) == 231          # 1.csv ≡ field_name_R
    assert len(set(chem) & set(d2.index)) == 1                      # 2.csv 与 1.csv 名字不通
    assert len(set(d2.index) & set(th["chemical_name"])) == 212     # 2.csv ≡ chemical_name
    assert len(set(d6.index) & set(th["chemical_name"])) == 44      # 6.csv 44/44 命中

    # ---- 5 量纲三值分类 + 硬证据覆盖（P0-3）----
    kind = classify_scale(d1, chem, cal)                            # 见附录 D
    assert set(kind.values()) <= {"log10", "linear", "log_unknown"}
    assert list(kind.values()).count("log10") == 182
    assert list(kind.values()).count("linear") == 33
    assert list(kind.values()).count("log_unknown") == 16
    for c in th.loc[th["threshold_mean"].notna(), "field_name_R"]:
        assert kind.get(c) in ("log10", "linear"), f"阈值化合物 {c} 落在 log_unknown"

    # ---- 6 数值护栏（P0-3）：作用在指数上，不作用在还原浓度上 ----
    for c in chem:
        if kind[c] != "log10":
            continue
        v = d1[c].values.astype(float)
        v = v[np.isfinite(v)]
        assert v.max() <= 20, (
            f"{c} 被判 log10 但 max(x)={v.max():.2f} > 20"
            f"（还原浓度 {10**v.max():.3g} 物理不可能），应降级为 log_unknown"
        )

    # ---- 7 检出限地板 ----
    FLOOR = -1.817819
    n_at_floor = sum(int(np.isclose(d1[c].values.astype(float), FLOOR).sum()) for c in chem)
    n_cols_floor = sum(1 for c in chem
                       if np.isclose(np.nanmin(d1[c].values.astype(float)), FLOOR))
    assert n_cols_floor == 142 and n_at_floor == 6807, (n_cols_floor, n_at_floor)

    # ---- 8 目标不是 0-6 整数分（无零膨胀）----
    for c in sen:
        vc = d4[c].value_counts(normalize=True)
        assert vc.iloc[0] < 0.10, c

    # ---- 9 派生列剔除（M1）----
    assert DERIVED <= set(chem), DERIVED - set(chem)
    pool = [c for c in chem if c not in DERIVED]
    assert len(pool) == 226, len(pool)

    return dict(d1=d1, d2=d2, d4=d4, d6=d6, d7=d7, cal=cal, th=th,
```

## 附录 D：量纲判读函数（三值 + 指数护栏，v3 已实测通过）

```python
GUARD_EXP = 20.0   # 指数 > 20 即还原浓度 > 1e20，物理不可能

def classify_scale(d1, chem, cal, guard_exp=GUARD_EXP):
    """返回 {列名: 'log10' | 'linear' | 'log_unknown'}。

    优先级：
      A 档  标定表硬证据（相对误差 < 1e-6）→ log10 / linear
      B 档  结构性规则（含负值 or 重复最小值）→ log10；再经「指数护栏」检验
      C 档  全正、对称、无地板 → log_unknown（已对数但底数不明）
    """
    kind = {}
    for c in chem:
        a = d1[c].values.astype(float)

        # ---- A 档：标定表硬证据 ----
        if c in cal.columns:
            b = cal[c].values.astype(float)
            m = np.isfinite(a) & np.isfinite(b)
            if m.sum() >= 30:
                with np.errstate(over="ignore", invalid="ignore"):
                    e_log = np.median(np.abs(10 ** a[m] - b[m]) / (np.abs(b[m]) + 1e-12))
                e_raw = np.median(np.abs(a[m] - b[m]) / (np.abs(b[m]) + 1e-12))
                if e_log < 1e-6:
                    kind[c] = "log10";  continue
                if e_raw < 1e-6:
                    kind[c] = "linear"; continue
                # CS2 / X4VG：标定表把 <LOD 记 0，只比 >0 的部分
                if (b[m] > 0).sum() >= 30:
                    mm = m & (b > 0)
                    if np.median(np.abs(10 ** a[mm] - b[mm]) / b[mm]) < 1e-6:
                        kind[c] = "log10"; continue

        # ---- B 档：结构性规则 + 指数护栏 ----
        v = a[np.isfinite(a)]
        if len(v) == 0:
            kind[c] = "log_unknown"; continue
        if (v < 0).any() or len(np.unique(v)) < len(v):
            if v.max() > guard_exp:          # 护栏作用在指数上
                print(f"[WARN] {c} 结构规则判 log10 但 max(x)={v.max():.1f} > {guard_exp}"
                      f"（还原浓度 {10**v.max():.3g}），降级 log_unknown")
                kind[c] = "log_unknown"
            else:
                kind[c] = "log10"
            continue

        # ---- C 档：全正无地板 ----
        kind[c] = "log_unknown"
    return kind
```

**实测（v3 跑过全表）**：

| 配置 | log10 | linear | log_unknown | 结论 |
|---|---|---|---|---|
| 无护栏 | 182 | 33 | 16 | 基准 |
| **护栏 `10**max(x) > 1e6`（错误写法）** | **67** | 33 | **131** | ❌ **误杀 115 个合法列** |
| **护栏 `max(x) > 20`（正确写法）** | **182** | **33** | **16** | ✅ 与基准一致，真实数据 0 次触发；且能捕获误判的双乙酰（max=121.73） |

> **为什么不能用浓度做护栏**：酒花萜类、酯类以 µg/L 计，正常的 log10 值可达 8–9，`10**8.3 ≈ 2e8` 完全合法。**只有指数本身过大才意味着误判**。这个坑 v3 自己踩过一次，写进论文可作为一个有说服力的工程细节。

> **为什么 C 档不叫 `linear`**：v2 把这 16 列叫 `linear` 是错的——它们偏度均值 −0.20（真线性列偏度均值 +6.36），说明**已经过对数化，只是底数不明**。叫 `log_unknown` 既诚实又能防止有人拿它们去做阈值判断。
