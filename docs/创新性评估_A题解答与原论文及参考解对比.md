## 1. 评估口径：什么叫"创新"

为避免"用了神经网络就叫创新"这类误判，本文用四级标尺：

| 级别 | 定义 | 判定标准 |
|---|---|---|
| **A 原创方法** | 新目标函数、新约束形式、或对既有算法的新用法，且该用法在两个对照系中均未出现 | 必须能指出"为什么这样定义问题"，而不只是"用了什么模型" |
| **B 有依据的差异化** | 别人没做、有量化收益、但方法本身是既有技术 | 需要消融或对照实验支撑收益归因 |
| **C 组合应用** | 把成熟组件按新顺序组装，或在新数据上重跑既有流程 | 不构成方法贡献，但可以是工程贡献 |
| **D 复现/退化** | 与对照系同构，或明显弱于对照系 | 不能主张创新 |

**一个先决判断：本队 Q1 的监督目标与参考解的目标之间只有 6.4% 的差距空间。** 用全样本最优仿射映射把 raw 面板均值映到 `4.csv` 的 z，逐维 R² 均值 = **0.9361**（见 §3.1）。因此"换监督目标"这个动作的天花板是 6.4%，而任何 Q1 方案之间的性能差异都被压在这个窄带里。**Q1 不该在性能上比高低，该在语义正确性上比。**

**关键前提：原论文不是"参考答案"，它是数据来源 + 基线。** 原论文的三个事实决定了本评估的基准线：

- 它只做**预测**（10 个模型横比，多输出回归，逐维 R²），trained panel R² 上限 0.22（ET/GBR/RF/XGB 并列）
- 它只做**归因**，且只两路证据（GBR 的 MDI + SHAP），目标是 consumer appreciation，不是 50 个感官维度
- 它**全文 0 处**生成建模（generative / GAN / VAE / latent / flow）。题面 Q3 的"生成"是原论文完全帮不上的部分

所以：**Q1/Q2 的原论文是"必须超越的基线"，Q3 的原论文是"无关文献"。** 这个区分决定了三问的创新压力完全不同。

## 3. 逐问深度分析

### 3.1 问题一：创新在哪、不在哪

**先说不在哪（必须诚实）：**

本队 Q1 的模型选取是 **D 级复现**。ExtraTrees 是原论文 Table 1 里并列最优的三个模型之一（ET/RF/XGB 均 0.22），本队既没有改造 ET，也没有像参考解那样做主模型谱系横比 + 堆叠。中位数插补 + clip + 取整更是标准操作。

同口径性能对比（都用逐维 R² 均值）：

| 方案 | 监督目标 | mean per-dim R² |
|---|---|---|
| 原论文 ET | trained panel QDA | 0.22 |
| 参考解 Stack | 官方 4.csv z | **0.2681** |
| 参考解 GBR | 官方 4.csv z | 0.2526 |
| **本队 ET（raw 目标）** | 真实 0–6 面板均值 | **0.2620** |
| **本队 ET（重标定到 z，乐观上限）** | 官方 4.csv z | **0.2522** |

结论明确：**在同一个 z 目标空间里，本队比参考解低约 0.016 R²**。参考解多出来的那 0.016 来自堆叠 + 图扩散 + 3 次重复降方差，是真实的工程收益。**Q1 不能主张性能超越。**

**再说在哪（可以主张的）：**

**创新点 1 — 监督语义的转换 + 一个可迁移的方法学结论（B 级）**

参考解拿 `4.csv` 的标准化连续值当监督，然后用保序线性映射把 z "造"回 0–6。这个做法有两个隐患：`4.csv` 已经中心化但**非单位方差**（std 0.370–0.723，极差 −2.151~6.172），逐维 min-max 映射会把不同维度的噪声结构放大成不同的量纲；而且映射出来的 0–6 分**不是任何品评员打过的分**，只是 z 的线性重标。

本队改用原论文补充数据 `Raw sensory data anonymized.csv`（2197 条逐品评员记录、250 款、每款 3–31 条、16 名品评员），聚合成啤酒级均值，直接在 0–6 上监督。这带来一个**两个对照系都没有的对照实验**：

> 同一模型、同一折划分：直接 raw 监督 MAE = **0.5062**；官方 z 监督 + 折内仿射标定 MAE = **0.5141**。配对 bootstrap 10000× 的差值 CI = **[0.00486, 0.01086]**，不含 0。

这个结论可泛化：**当外部存在真实量表标签时，直接在该量表上监督优于"在标准化量表上训练再标定"**。它不是本数据集的特殊性，而是"标签-semantic mismatch 会损失信息"的一个实证。参考解没有这个对照，因为它根本没拿到 raw 数据。

**必须同时披露的边界**：这两套标签不是独立的。raw 面板均值与 `4.csv` 逐维 |Pearson| = **0.9041 / 中位 0.9777 / 0.9934**，且是**同一批 250 款啤酒**。所以 5 折 OOF 是"同分布内的交叉验证"，**不是独立外部验证**。这个对照只能说明"监督目标的选择"，不能说明"模型泛化到了新啤酒"。

**这个创新的真实幅度——必须自己先算出来，否则会被评审算出来：**

我额外算了"两个目标之间的换算上限"：用**全样本**最优仿射映射把 raw 面板均值映到 `4.csv` 的 z，逐维 R² 均值 = **0.9361**（中位 0.9558，最低 0.8173，最高 0.9868）；反向同样 0.9361（关系近似线性可逆）。

这意味着：

> **两套监督目标之间有 93.6% 的信息重合。因此"换成 raw 监督"这个动作能带来的性能提升，上限本来就只有 6.4%，实际观测到的是 MAE 改善 1.5%（0.5141→0.5062）。**

换句话说，`0.0078` 的 MAE 改善与"上限 6.4%"是**自洽的，但也不惊艳**。所以创新点 1 的正确强度评级是 **B−（有依据但收益有上限）**，不是"A 级"或"重要突破"。它的价值在于**把一个默认选择变成了有证据的选择**，而不是"发现了更好的监督方式"。论文里如果把它写成核心创新，会被这个 0.9361 直接反驳。

更诚实、也更有力的表述是：

> "我们验证了两套可用监督目标之间的线性可换算程度（逐维 R² 均值 0.936），并在此基础上确认：直接在真实量表上监督，相比'标准化量表训练 + 事后标定'仅带来 1.5% 的 MAE 改善（配对 bootstrap CI 不含 0）。这一改善幅度与两目标 93.6% 的重合度一致，因此我们不把它作为主要性能来源，而作为**监督语义正确性**的一个论证。"

这段话比"我们比参考解监督得更好"强得多，因为它先自证上限、再报结果。

**创新点 2 — 把评分卡父子结构当模型筛选器（B 级）**

评分卡里 6 个"总体强度"父类（`A_malt_all`、`A_hops_all`、`A_esters_all`、`F_malt_all`、`F_hops_all`、`F_esters_all`）各有 4 个子属性。语义上"某类香气总体强度"不可能低于其任一子属性。审计结果：**14989 个非零子父对，0 违规** —— 这是数据本身的硬结构。

关键在于这个结构**可以直接筛模型**：

| 模型 | 30 项 MAE | 父子违规数 |
|---|---|---|
| MeanRaw | 0.6049 | **0** |
| RidgeRaw | 0.5584 | **71** |
| Ridge → z → 标定 | 0.5611 | **66** |
| **ExtraTrees** | **0.5062** | **0** |
| ET → z → 标定 | 0.5141 | **0** |

也就是说：Ridge 虽然 MAE 还行，但**它输出违反评分卡语义**（71 处子属性高于父属性）。ExtraTrees 天然满足。这构成一个"性能 + 语义合法性"的双重筛选理由，而不是单纯挑 MAE 最低。

参考解**完全没有这个维度**——它的 11 个模型横比只看 R²，不检查父子单调性，保序映射也不保证单调（逐维独立线性映射必然破坏父子的相对关系）。本队这一点是**真实的、可复现的、有数据支撑的差异化**。

**创新点 3（反向）— 图扩散特征的消融其实证明了"不要图"**

参考解最显眼的"创新"是共表达图扩散特征 `X^d = S X`，`S=(1−α)I+αÃ`。但它的消融表 A0–A4 全在 0.2242–0.2279 之间，三项增强**全部零增益或负增益**（图扩散 −0.0031、缺失指示 −0.0037、封底指示 −0.0026）。

这个结果对**本队反而有利**：它说明在本数据规模（n=250、p=231）下，图扩散特征没有信息增量。本队不用图扩散、不做缩放、只有 231 列原始值 + ExtraTrees，拿到同口径 0.262 —— **用最少的加工达到同一水平**，这本身是一个可以被引用的"简约性证据"。但注意：这不是本队主动做的消融，是**参考解替本队做了**，不能当作自己的实验主张。

### 3.2 问题二：本队创新度最高的地方

#### 3.2.1 为什么这是真创新：目标函数的替换

把三方的问题定义并排看：

- **原论文问**：哪些化学参数对 consumer appreciation 的模型贡献大？（答案：MDI/SHAP 排名）
- **参考解问**：哪些化合物在五路证据下被共同推举为某感官维度的关键化合物？（答案：秩融合排序 + 稳定性 + 化学可解释性）
- **本队问**：**哪 3 个化合物组成的集合，能在留出数据上最好地预测该感官维度？**（答案：Spearman 前 2 + 残差条件增益第 3，然后用同一套 3 特征 Ridge 验证）

这三个问题**不是同一个问题的三种解法，而是三个不同的问题**。

参考解那条路（五路秩融合）是**归因（attribution）**：它继承自可解释机器学习，问的是"已经训练好的强模型在看哪些特征"。它有一个结构性缺陷：SHAP 权重给到 0.35（最高），而 SHAP 是从"用全部 231 特征训练的 GBR"里读出的局部贡献——**它衡量的是"在完整模型中该特征的边际重要性"，而不是"去掉其他 230 个特征后它还能不能单独预测"**。在有 231 个强共线变量的场景下，这两个量会显著分歧：一个特征可以在完整模型里 SHAP 很低（因为共线伙伴已经解释了方差），但在 3 特征子集里很强；反之亦然。

本队那条路（条件增益）是**组合优化**：`argmax g_j` 就是**正交匹配追踪（OMP）的平方增益准则**，做前向逐步残差化。算法本身不新（是 forward stagewise / OMP 的教科书形式），但：

1. **用法是新的**：把它用在"化学 → 感官"的 Top-3 归因上，让"第 3 个化合物"的意义从"排名第三重要"变成"**在前 2 个已解释的方差之外，能带来最多新信息的那一个**"。这个语义转换让 Top-3 成为一个**有明确目标函数的集合**，而不是"排名前 3 的三个个体"。
2. **可证伪**：它能被同一个 3 特征 Ridge 直接检验。参考解的方法**无法被检验**——因为秩融合的输出没有预测目标，"综合分 0.9632 的那 3 个化合物"好不好，没有可比的基准。

这就是本队 Q2 最核心的创新：**把归因问题转化成了可验证的预测问题**。这也是两个对照系都没做的一层（我在参考解 `src/03_q2.py` 全文检索 `mae|MAE|KFold|predict|r2|R2`，只命中用来算置换重要性的 `r2_score`，没有任何 Top-3 的预测性评估）。

#### 3.2.2 候选集净化：一个被忽略但真实的严谨性优势

参考解的候选集是**全 231 列**。看它的 `output/q2_module_summary.csv`：

- module 0（64 个成员）含 `color.EBC.`、`pH`、`protein.g.L.`、`acetic_acid.g.L.`、`lactic_acid.mg.L.`
- module 1（41 个成员）含 `iron`、`bitterness`
- module 11/12/13/14 分别是 `betaglucan.mg.L.`、`GFS`、`CO2.PSI.`、`propylene.glycol` 单点

而题面 Q2 问的是"**哪些化合物**"。pH 不是化合物，color/EBC 是仪器综合指标，bitterness 本身就是感官量（放在 X 里预测感官是循环论证），GFS/CO2.PSI 是工艺参数。参考解把这些都算进"关键化合物"候选，在语义上是有瑕疵的——它的 Top-3 表里"酸度"Top-1 = `Total acids`、"苦度"Top-1 = `Ethyl octanoate`，前者的"化合物"属性就很勉强。

本队明确排除 13 个非单一化合物/聚合指标，候选集 **218 个真实化合物**。这个净化没有增加性能，但让"关键化合物"这个答案**在语义上站得住**。这是一个 C 级但重要的严谨性差异。

另外本队做了一件参考解没做的事：**直接锚点审计**（`results/q2/q2_chemical_anchor_audit.csv`）—— 拿 12 个有已知化学对应的感官维度，检查"已知标记物是否被选中"：

|---|---|---|---|---|
| alcohol | `ethanol..v.v.` | +0.817 | 1 | ✅ |
| X4vg | `X4VG` | +0.473 | 1 | ✅ |

这张表是本队 Q2 最有学术诚实度的产物：**它主动暴露了三个教科书级缺陷标记物（DMS、双乙酰、反式-2-壬烯醛）在数据里根本没有线性关联**（ρ 分别 0.088 / −0.098 / −0.151，排名 90 / 85 / 19）。这意味着"用统计关联找关键化合物"这条路本身对这三项失效——原因很可能是检出限左删失（48 列 ≥25% 样本堆在最小值，DMS/双乙酰正在其中）把真实变异压缩掉了。

#### 3.2.3 阴性结果的诚实报告：不是创新，但是稀缺品质

本队 Q2 明确报告：

> Top-3 的平均 Jaccard：Spearman **0.2665** vs 条件增益 **0.2270**（更低）；50 维中只有 13 维 Jaccard 改善，28 维 MAE 改善。

即：**新方法预测更准，但选择更不稳定。** 而且在 `summary.json` 里写死了 `reliability_note: "Stability is worse than Spearman; cannot claim across-metric dominance."`

参考解在这一点上是同类：它自曝"全维平均 J=0.20"，最低到 0.02。**两个方案撞上了同一堵墙**：

> **在 231 个强共线化合物里做 Top-3 选择，本身就不稳定。** 这不是方法缺陷，是问题的性质——共线变量之间存在大量"等价替代"，任何选择准则都会在重采样下跳变。

这个诊断比任何单一方法的优劣都更有信息量。本队把它写进了结果而不是藏起来，这在与评审对线时是**加分项**（因为一旦被问到"你的 Top-3 稳定吗"，你已经有答案）。

#### 3.2.4 Q2 的真实短板

- **效应量小**：MAE 从 0.38009 到 0.37276，绝对差 **0.00733**（标准化单位）。虽然 CI 不含 0，但这是"统计显著、实践微小"的典型。
- **k 敏感性没做**：只对 Top-3 这一个 k 验证。如果 4 特征或 5 特征下条件增益反而不如 Spearman，结论就不稳。
- **深图消融是负结果**：本队试过 signed graph + 稀疏神经归因，真实图 0.41083 / 打乱图 0.41132 / 无图 0.41263，seed 平均后真实图（0.39205）**略差于**无图（0.38988），CI [−0.00662, 0.00215] 跨 0。这条路被正确降级为 ablation，但它意味着"图结构对选择没帮助"——与参考解"图只用于解释"的定位恰好一致，两方独立得出同一结论。

### 3.3 问题三：弱在生成、强在协议与校准

#### 3.3.1 生成模型：本队输了，而且是硬输

| | 参考解 | 本队 |
|---|---|---|
| 潜维数 | K=14（并行分析定阶，累计 54.7%） | K=12（无依据固定） |
| 模型 | 6 层仿射耦合归一化流，1200 epochs | 收缩高斯；对照流 260 epochs |
| 选模型口径 | **样本内**（全部 220 样本） | **留出集**（48 款留出） |
| 结论 | 流 −19.03 ≪ 高斯 +10.61（**差 29.6 nats**） | 高斯 14.00 < 流 19.85（差 5.85） |
| SWD | 未在留出上算 | 高斯 0.7041 < 流 0.7419 |

**参考解的条件流是真训练出来的、且明显优于高斯。** 本队的高斯"胜出"需要解释，而不是庆祝。三个原因：

1. **本队的流严重欠训练**。看 `q3/results/flow_training_curve.csv`：训练 NLL 从 epoch 1 的 16.95 降到 epoch 200 的 **3.07**，**还在单调下降**。260 epoch 远未收敛（参考解用 1200）。用未收敛的模型做对照，得出的"高斯更好"结论不成立。
2. **口径不同，而且本队更严格**。参考解的 `nll_gauss` 是在 `Zn`（全部 220 个训练样本）上算的，`flow` 返回的 `best` 也是训练过程中的最小训练 NLL —— **两边都是样本内**。本队是在 48 款留出上算的。样本内比较天然偏向更灵活的那个模型（流有 6 层 × 64 隐单元），所以参考解的"流胜"有乐观偏差。
3. **条件更苛刻**：本队 202 训练样本、22 个风格（含 3 款的 Faro、4 款的 Brut）；参考解 220 样本、16 风格。风格更多、每风格更少，条件流更难学到。

**所以正确的表述是**：在 "202 训练样本 / 22 风格 / 260 epoch" 的约束下，条件流没有体现出对收缩高斯的优势；参考解在 "220 样本 / 16 风格 / 1200 epoch / 样本内评估" 下得到相反结论。**两者不可直接比较，且本队不能用"高斯更好"去否定参考解。**

但这里有一个**被本队作者自己低估的方法论优势**：用留出集而不是训练集来选生成模型，是更正确的做法。参考解在训练集上比较 NLL 然后选流，属于样本内模型选择；本队在留出集上比较，属于泛化误差估计。**这个协议选择本身可以主张，即使它的结论（高斯胜）因为欠训练而不够强。** 一个更稳妥的表述是：

> "我们在留出协议下比较了条件流与收缩高斯；在该样本量与训练预算下流未收敛，因此我们不宣称'高斯优于流'，只宣称'在本文的可验证协议下未能证明流更优'。"

这个表述既保住了诚实，又保住了方法论的正确性。

#### 3.3.2 检测下限堆积校准：本队唯一一处 A 级原创

这是三问里**唯一没能从任何对照系里找到对应物**的东西。

**问题发现**：`1.csv` 的 231 个化学列中，**7667 个格子（13.28%）等于所在列的最小值**；**102 列有 ≥5% 样本堆在最小值**，**48 列有 ≥25% 堆在最小值**。堆积最重的：`X6.methyl.5.hepten.2.one` 84.8%、`limonene` 84.8%、`CS2` 83.6%、`cis.dihydro.beta.terpineol` 81.2%。

对一个连续浓度变量来说，80% 的样本取到**完全相同的最小值**，唯一合理解释是**仪器检出限下的"未检出"被统一记为下限值**——即左删失（left-censoring）。这不是"最小值恰好常见"，是测量机制的产物。

**参考解怎么处理的**：`src/01_audit.py:249` 记了 `n_censored`，`src/02b_ablation.py:49-51` 用 `floor_frac>=0.05` 标记删失列（102 列）并算作一个数据契约，`src/05_fig_data.py:84-87` 画了堆积直方图。但在**生成**环节（`04_q3.py`），它只用 `DEF_FLOOR` 做缺陷投影的下限夹逼，**没有对生成分布的离散概率质量建模**。结果是：生成谱的"未检出比例"与真实谱不一致——因为高斯/流都是连续分布，采到恰好等于最小值的概率为 0。

**本队怎么处理**（`q3_censor_finalize.py`）：对 48 个堆积变量，为每个（风格 s, 变量 j）建一个**贝叶斯收缩的最小值概率模型**

```
p̂_js = (n_js^min + 10·p_j) / (n_s + 10)
```

其中 `n_s` 是该风格训练样本数、`n_js^min` 是取到最小值的样本数、`p_j` 是全体样本中该变量的最小值比例。然后生成时先按 `p̂_js` 决定该格是否为"未检出"，是则置为列最小值，否则从截断后的连续部分采样。

**量化收益**（`q3_censor_repeated_summary.json`，三套留出分裂）：

| 分裂种子 | 校准前地板比例 MAE | 校准后 | 相对降幅 |
|---|---|---|---|
| 77 | 0.43139 | 0.25296 | **41.36%** |
| 99 | 0.43581 | 0.25083 | **42.44%** |
| 20261027 | 0.41091 | 0.25487 | **37.97%** |

平均绝对改善 0.17315，cluster bootstrap 95% CI **[0.13048, 0.20642]**（不含 0）。覆盖 960 个（风格 × 变量）对、20191 个地板格、物理列 min/max 违规 **0**。

**为什么这是真的创新（A 级）**：

1. 它识别出了**连续生成模型的结构性失效模式**——离散原子（检出限下的点质量）无法被连续密度表示。这是一个**先验就会想到、但生成建模文献里常被忽略**的问题。
2. 它给出了一个**风格条件的两部分模型（two-part model）**：`p(未检出 | 风格)` 用 Beta-二项收缩估计，`p(值 | 未检出, 风格)` 用截断连续分布。这个结构在计量经济学里叫 hurdle/two-part model，在化学计量学里叫 censored-data model，**但把它套到"风格条件生成"上、并用来重标定生成谱的离散质量，这是新的用法**。
3. 它有**严格的边界声明**：`indicator_definition` 明确写 "same observed column minimum in >=25% of training beers (possible detection floor; **not proven LOD**)"，notes 写 "artificial minima are proxies, not proven instrument censor values"。不越界。

**必须同时说的限制**：这个改进只提升**地板出现频率的保真度**，不提升 231 维生成谱的**整体质量**。不能写成"生成质量提升 40%"。本队文档这一点的表述是正确的（`docs/第三问_实测结果与方法验证.md` 明确区分），但论文正文如果只写"相对误差下降 38%–42%"而不加限定，会被误读为整体质量。

#### 3.3.3 迁移算法：两种哲学，本队更激进、参考解更保守

这是 Q3 里最有分析价值的一处对比，因为**两方用了同一个传输数学（Bures–Wasserstein），但处理缺陷约束的哲学完全相反**。

**参考解：单调连线 + 二分搜索（保守插值）**

```
z(λ) = (1−λ)·z_s + λ·z_ot,   λ* = max{λ ∈ [0,1] : D(z(λ)) ≤ D(z_s)}
```

22 步二分，精度 2⁻²²。语义是"在**不引入缺陷**的前提下，最多能往目标风格迁移多远"。这是一个**构造性保证**：只要 D 单调，λ* 一定存在且合法。
实测：λ_mean = 0.804，缺陷恶化 4→3，p_tgt 0.0→0.636。

**本队：候选优化（激进搜索）**

```
从 Tripel 条件分布抽 100 个候选 + 1 个 OT 提案
→ 5 个预声明凸混合因子 α ∈ {0.10, 0.25, 0.50, 0.75, 1.0}
→ 先把候选的 4 个化学缺陷项 clip 到 ≤ 源值（保证线段上全部点合法）
→ 在硬约束下最小化 ‖z−μ_Tripel‖ + 0.15·‖z−z_s‖，且源漂移 < 6 潜单位
```

实测：11 款均值距离 **2.9018 → 1.7716**（比参考解的 2.5607 更近）、7/11 更近、0 违规。

**这个对比怎么评价？**

| | 参考解 | 本队 |
|---|---|---|
| 数学保证 | **有**（λ* 存在性靠 D 单调性） | 无解析保证，靠**穷举 + 断言**（`assert` 每款都验 5 项） |
| 迁移幅度 | 保守（λ 平均 0.80，但受 D 约束限制） | 激进（1.7716 vs 2.5607） |
| 成功款数 | **11/11 更近** | **7/11 更近**（4 款未动） |
| 缺陷恶化 | 4→3（**仍有 3 项**） | **0**（42 项实测比较） |

**这里有一个必须点破的口径问题**：本队的 "1.7716" 是 **11 款均值**，其中 4 款 `chosen_proposal=unchanged`（α=0，before=after）也被计入。所以"距离大降"部分来自 7 款的大幅改善、部分来自 4 款的 0 改善。参考解是 11/11 全部移动、但幅度受限于 D 约束。

**两个方案的优劣取决于你怎么定义成功**：
- 若"成功 = 每一款都更接近目标" → 参考解赢（11/11 vs 7/11）
- 若"成功 = 在零缺陷违规下尽可能接近目标" → 本队赢（1.7716 且 0 违规，参考解 2.5607 且 3 项恶化）

**这不是"本队更强"，是"两个不同的取舍"。** 论文里如果只说"我们的距离更小"，会被问"为什么不看 11/11"；如果只说"我们 0 违规"，会被问"为什么 4 款没动"。**唯一能站住的表述是把两者都摆出来，说清这是 constrained-optimal vs conservative-feasible 的差异。**

本队这一处的**真实创新点**是那个 "clip 到 ≤ 源值 → 保证线段上所有点合法" 的技巧：因为约束是**单调非增**，只要端点合法，凸组合就合法（单调性是线性保持的）。这让"100 抽样 + 5 混合因子"这个看似暴力的搜索**有了合法性证明**。这是一个小巧但正确的方法论细节，值得写出来。

#### 3.3.4 陈酒花代理约束：本队的一处风险，不是创新

参考解明确写了："对反式-2-壬烯醛与陈酒花**不编造阈值**" —— 因为 `1.csv` 里没有同名的陈酒花化合物浓度，也没有可靠的感官阈值。

本队的做法是：用 **Q1 模型预测的 `stale_hops` 感官分**作为约束，要求迁移后不高于源值。

这看起来更"完整"（5 项全约束 vs 4 项），但学术上更危险：

> Q1 模型在 `stale_hops` 这一维的 R² 是模型中下水平（整体 30 项 MAE 0.5062，mean per-dim R² 0.262），用它做**硬约束**等于"用一个 R²≈0.26 的模型保证某件事不发生"。

参考解的回避是保守但正确；本队的"完整"是**把不可靠的东西升格成了保证**。这一处**不能主张为创新，应主张为"在披露模型可靠性前提下的可行性约束"**，并且必须写明：`stale_hops` 的"0 违规"是**模型代理层面**的，未经人工品评验证。

本队文档（`docs/第三问_实测结果与方法验证.md`）确实写了这一条，但论文正文的表述需要更重。这是 Q3 最容易被评审击穿的一个点。

## 4. 跨问系统层：链路设计是两个方案都做得好、但重点不同的地方

**参考解的系统性优势**：把"对数底数、量纲混用、检出限删失、0–6 分制标定"四件事固化成一个**三问共享的数据契约**，在第二章定义一次，后面三问全部引用。这是**论文级的工程纪律**，本队没有对应的集中定义（虽然各问各自做对了）。

**本队的系统性优势**：三问的**链路更短、闭环更一致**。

```
官方 X (250×231) + 评分卡
    ↓ Q1: ExtraTrees → 0–6 分 + 化学→50维感官代理
    ↓ Q2: 4.csv 目标 + 条件增益 → 50×3 化合物
    ↓ Q3: 风格条件生成 → 880×231 → Q1 代理画像 → Pils/Lager→Tripel
```

关键在最后一环：**Q3 的感官画像和 Q3 的陈酒花约束，用的是同一个 Q1 模型**。参考解的 Q3 代理是另训的 XGB（`sens_surrogate_r2 = 0.23786`），与它 Q1 的 Stack 不是同一个东西 —— 这意味着参考解的 Q3 约束链条与 Q1 结论之间存在**模型不一致**。本队用同一个 ET，链条一致。这算一个 B 级的系统性优点（更少的模型 = 更少的不一致来源），但它同时也是本队 Q3 代理精度只有 R²≈0.26 的原因（没有为 Q3 单独优化代理）。

## 5. 三方共同撞上的墙（这部分比"谁更创新"更有价值）

**墙 1：250 个样本是硬上限。**
- 原论文最好的 trained-panel R² 只有 0.22
- 参考解堆了 11 个模型 + 图扩散 + 3 次重复，做到 0.268
- 本队直接 raw 监督做到 0.262

三条独立路径，收敛到 **R² ≈ 0.22–0.27**。这不是模型选择问题，是**样本量 × 标签噪声**的联合上限。原论文自己解释了：panel 数据本身有品评员间差异（本队算的 leave-one-panelist-out MAE 是 **1.0654**，远大于模型误差 0.5062 —— 也就是说**品评员之间的分歧比模型的误差还大一倍**）。

这个数字（1.0654）应该成为所有三问结论的**分母**：任何"预测精度提升 1.9%"的主张，都必须放在"人类品评员自己就有 106% 的分歧"这个背景下理解。

**墙 2：231 个强共线化合物让"关键化合物"本质上不可辨识。**
- 参考解五路秩融合：全维平均 Jaccard **0.20**
- 本队条件增益：Jaccard **0.2270**（vs Spearman 0.2665）
- 两方都低

这不是方法的问题。当 `limonene` 和 `X6.methyl.5.hepten.2.one` 有 84.8% 的样本同时取最小值时，它们在任何子集里都是**等价替代品**，任何准则都会随机选一个。

**墙 3：检出限删失让三个教科书标记物失效。**
DMS（ρ=0.088，排名 90/231）、双乙酰（ρ=−0.098，排名 85）、反式-2-壬烯醛（ρ=−0.151，排名 19）—— 这三个是最著名的啤酒缺陷化合物，但统计上完全选不出来。原因几乎肯定是左删失把变异压缩了。两方都**没有解决**这个问题（参考解绕开、本队暴露），这是本题真正的开放问题。

## 7. 若要提升创新性主张，最小改动建议

按"投入产出比"排序，只有前两条值得做（其余属于论文写作而非方案改造）：

**① 补 k 敏感性（半天工作量，直接加固最强创新点）**
对 k=2,3,4,5 重复"条件增益 vs Spearman"的对比。如果条件增益在 k=4/5 时优势扩大，则"最小充分集"这个论点从"3 的巧合"升级为"随 k 的系统性优势"。这是 Q2 创新点的**唯一软肋**，补上就闭环。

**② 把流的训练补到收敛（1–2 小时，救回 Q3 的对照有效性）**
当前 260 epoch 训练 NLL 仍 3.07 下降中。跑到 1200 epoch（参考解的量级）再在留出集上比 NLL。两种结果都有价值：
- 若流反超 → 本队得到"**留出集上流也优于高斯**"的更强结论，且证明参考解的样本内选择在留出协议下依然成立（这是对参考解的独立验证，学术上很漂亮）
- 若流仍输 → 本队得到"**在 202 样本 / 22 风格下流确实不占优**"，与参考解的 220 样本 / 16 风格形成有意义的对照（说明风格数而非样本量是关键变量）

**③ 明确"目标函数替换"的表述（纯写作，零成本，但最影响评审印象）**
现在的 `docs/第二问_提交候选结果与创新审查.md` 把它写成"条件增量稀疏选择"，读起来像工程改进。应该改成：

> "我们把'关键化合物识别'重新定义为'在给定基数约束下最小化预测误差的集合选择问题'。与通行的归因路线（SHAP / MDI / 秩融合）不同，我们的输出有可证伪的预测目标，因此可以用留出数据直接检验集合质量。这一步使我们能够回答通行方法**无法回答**的问题：这 3 个化合物是不是**足够**的？"

这段话不增加任何计算，但它决定了评审把这项工作归到"组合优化"还是"又一个 Top-3 排名"。
