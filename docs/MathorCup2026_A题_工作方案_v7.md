# 啤酒酿造化合物分析与啤酒风味预测 —— 工作方案 **v7**

> **本版定位**：v1–v6 的**数据事实层**与**协议层**（混合量纲三分、名字桥、派生列、检出限地板、第 73 行机理、2×2 止血点、公平基线、`beer` 主键、`R²≈η²`）经六轮独立复现，**全部通过，原样保留**。**v7 只做四类改动**：
> 1. **`crosswalk` 不用猜了**。`3.xlsx::summary` 的 50 个评分列**每一格都是公式** `=beer_k!$Q$r`（行 `r` 恒指 `beer_{r−1}`，无一例外）——**官方 crosswalk 就写在附件里**。照抄公式后能对平：卡上 **54 个评分格** → 50 列去重占 **49 格** → 未用 **5 格**（`Q45` `AG45` `AG62` `AG90` `AG94`）。并查出**官方表一处笔误**：`summary` 的 `barnyard` 与 `stale_hops` **同指 `AG76`**，而卡上 `Barnyard/horsey` 的评分格是 `AG90`。
> 2. **层内 R² 第三次被推翻，这次是分母错了**。v6 用"训练折组均值"当基准，`Σ(y−ĝ_group,train)²/SS_within = 1.234`，**分母被高估 23.4%**，R² 凭空抬高约 0.23。还原成**固定效应分母**后，α=1…1e4 **全为负**（最好 −0.173，`RidgeCV` −0.137）→ **"风格内部没有可学的映射"这句话终于有了严格版本**。
> 3. **门控从"3 档缩尾"补成 9 配置（3 档 × 3 seed）**：可达数实为 **32–36**，三色分层改为 **●27 / ◐14 / ○9**，并给出**阈值敏感性**（`th` 0.50→0.90 时 ● 从 36 滑到 25）与**逐维 `x/9` 计数**——"27"这个数字必须连同阈值一起报，否则不可复现。
> 4. **Q2 的两条判据被数据改写**：`§5.1` 的"模块按**风格**组织"被否证（`r(|ρ|,√(η²ᵢη²ⱼ)) = 0.058`，风格最多解释 **0.3%**）；"ARI 0.05–0.07 接近随机"是统计错误（正文口径 9 模块、ARI **0.0764**、置换零分布 sd **0.0073** → **10.6σ，p<0.001**，是"**弱但显著**"）。因此 **L2 判据的理由失效，L1 升为唯一可辩判据**。
> 另：Q1 的主表口径正式定为**主表 250×52 + 附表 C 12×52**，并补上 12 行留出验证的**零分布与 bootstrap CI**（置换 500 次 p<0.0002，12 行 CI [0.294, 0.505]，**逐维 ρ 的 CI 宽度中位 1.05** → 逐维排名不可用于决策）。

### 1.2 1.csv 是混合量纲，不是单一 log10

**判定方法（硬证据）**：用 `8.xlsx::Calibrated chemical dataset`（250×73）与 1.csv 逐列比对，检验 `10**x == calibrated` 还是 `x == calibrated`（相对误差 < 1e-6）：

```
确认 log10  : 37 列   例：DMS / bitterness / pH / acetaldehyde / ethyl_acetate
确认 线性   : 33 列   例：X2.3.butanedione(双乙酰) / linalool / geraniol / X.E..2.nonenal
            37 + 33 = 70 列有硬证据，剩 161 列需结构推断
```

> **关键细节**：`CS2` 与 `X4VG` 在标定表把"低于检出限"记为 0，1.csv 记为列专属地板（CS2 −2.146292，X4VG −2.013157）。在标定值 > 0 的样本上 `max|10**x − cal| = 7.1e-10` → 这两列也是 log10。

| 类别 | 列数 | 证据 | 用途 |
|---|---|---|---|
| **`log10`** | **182** | 70 列有标定表硬证据，其余经结构规则 + 指数护栏 | 可做绝对阈值判断 |
| **`linear`** | **33** | **全部**有标定表硬证据 | 可做绝对阈值判断 |

`log_unknown` 16 列清单：
`X.E..beta.ionone, X2.methyl.1.butanol, X3.furanmethanol, X3.methyl.2.butenal, X3.methyl.2.hexanol, aroma_hops_sum, ethyl.benzoate, ethyl.hex..3E..enoate, isoborneol, isopentyl.formate, n.heptanol, n.octanol, n.pentanol, nonan.2.ol, terpinolene, trans.dihydro.alpha.terpinyl.acetate`

> **⚠️ 实现陷阱（v4 实测，写代码时必看）**：硬证据判据必须用**中位数**相对误差，**不能用最大值**。标定表个别行的舍入噪声可达 1e-4，一旦用 `np.max`，**33 个真线性列会全部失去硬证据**、退化成结构规则而被判成 log10 → 实测得到 `204 / 1 / 26` 而不是 `182 / 33 / 16`。
> 正确写法：`np.median(|10**x − cal| / (|cal| + 1e-12)) < 1e-6`，并要求双方都有值的样本对 **≥ 30**。附录 D 已是修正版，可直接照抄。

> **一致性说明**：`aroma_hops_sum` 同时出现在此清单与 §1.3.1 的"派生列必删"清单中，**不是重复计数**——前者说它的**量纲不可判定**，后者说它的**变量性质是派生量**。它在 Q2 被剔除，故量纲问题不影响任何 Q2 结论。

**P0-3 的核心警告**：结构回退规则（"含负值或有重复最小值 → log10"）在 70 个可标定列上实测：

```
precision(log10) = 0.565      recall(log10) = 0.946
真 log10 → 判 log10 35 / 判 linear 2
真 linear → 判 log10 27 / 判 linear 6
```

27 个假阳性**全部是"含 0 或重复 0"的真线性嗅感化合物**，**恰好包括双乙酰与 t2n**（Q3 核心缺陷物）：`X2.3.butanedione, X3.methylbutanal, ethyl.isobutyrate, ethyl.butyrate, methylpyrazine, furfural, X3Z.hexenol, n.hexanol, amyl.acetate, benzaldehyde, X5.methylfurfural, hexyl.acetate, benzyl.alcohol, phenylacetaldehyde, X.E..beta.ocimene, linalool, X.E..2.nonenal, X1.alpha.terpineol, ethyl.nicotinate, citronellol, geraniol, X.E.E..2.4.decadienal, gamma.nonalactone, X.E..beta.damascenone, Z.nerolidol, ethyl.pentanoate, X2.ethyl.3.methylpyrazine`。
`X2.3.butanedione` 的 max = **121.73**，若误判为 log10 则 `10**121.73 = 5.4e+121`，阈值判断全错。

→ **护栏必须作用在指数上，不能作用在还原浓度上**。写成 `10**max(x) > 1e6` 会**误杀 115 个合法 log10 列**（酒花萜类以 µg/L 计，`10**8.3 ≈ 2e8` 完全正常）。正确写法是 **`max(x) > 20` 即降级**：实测真实数据 **0 次触发**，且能捕获误判的双乙酰（max=121.73）。

| 触发列 | `X2.methyltetrahydrofuran.3.one`，全局 mean **51.2855**、全局 std **796.633** |
| 触发样本 | **第 73 行**，风格 **Kriek**，该列取值 **12596.4**（全局 z = **15.75**） |
| 关键机制 | 该行落在**测试折**时训练折排除它 → 训练 std 从 796.633 **塌缩到 6.54183（1%）** |
| 后果 | 该行测试时被放大到 **z = 1925**；Ridge 在 `acetic` 上外推到 **+64.8**（真值 −0.28），该维 R² = **−30.78** |
| 传染 | 一行污染 10+ 维（`A_malt_all` 预测 −43.0、`F_malt_burn` −38.9、`F_malt_all` −38.0、`co2` −28.6、`clove` −23.1…），50 维均值被拖到 **−2.94** |

**第二步：把两个操作拆开做 2×2（这是 v5 的核心修正）**

只有两件事可能止血：**训练折缩尾** 与 **测试折裁到训练支撑集**。四格全跑（3 个 seed，下表 seed=0，其余见括号）：

| | **测试折不裁剪** | **测试折裁到训练 [p1,p99]** |
|---|---|---|
| **训练折不缩尾** | ① **−2.943**（裁剪输出后 +0.191） | ③ **+0.220** ← **止血点在这里** |
| **训练折缩尾[1,99]** | ② **−12.384**（裁剪输出后 +0.119） | ④ +0.222（v4 定稿） |

> **论文必须这样写**：**唯一起作用的是"把测试样本的取值限制在训练折支撑集内"，缩尾不是原因。**
> 三证据：
> 1. **只缩尾训练折（②）比什么都不做（①）更差**——从 −2.94 掉到 **−12.38**。因为缩尾把训练 std 压得更小（796.6 → 6.5 → 更小），那个 12596 反而被**放大得更狠**（`max|残差|` 65.0 → **138.8**）。
> 2. **完全不缩尾、只裁测试折（③）直接得到 +0.220**，与 v4 定稿 ④ 的 +0.222 只差 0.002。
> 3. 跨 seed 确认：③ = +0.220 / +0.210 / +0.218，④ = +0.223 / +0.211 / +0.221，**两档在三个 seed 上差 ≤ 0.003**。而 ① 与 ② 分别稳定在 −2.94 与 −12.4 量级。

**② 这个"更差"的结果是加分项，不是减分项**：它恰好构成一个干净的对照实验，证明"缩尾降低方差"这个直觉在此处是**反向的**——离群值单行支配方差时，压方差等于放大杠杆。

**第三步：由此得到本节真正的正面结论**

> **模型的有效域由训练支撑集决定，不由正则化决定。**
> 一个样品的预测只有在其**每个预测值都落在训练折观测区间内**时才在域内；落在区间外的一律被截断，属于外推受限，**不能声称可信**。实测（seed=0、winsor[1,99]）**86.0% 的测试样品至少有一个化合物被截断**，共 **1176 个单元格**——这不是边角情况，而是常态。因此"裁剪"不是调参技巧，而是**对有效域的显式声明**。

> **补充实测（v5 加，防止被问"你的 min/max 是全量还是折内"）**：把裁剪区间从"全列 min/max"换成"**逐折训练折 min/max**"（严格无泄漏），结果 **mean +0.2228 / median +0.1590 / 49/50，逐维最大差仅 0.0010**——两种口径实质等价。原因是每折约 200 个样本时，训练折极值已稳定覆盖总体极值。**论文里统一写"训练折支撑集"，并附这条校验**，比含糊写"训练范围"稳。

**第四步：α 与预处理的相对重要性（v4 结论保留）**

稳健协议（③ 或 ④）下，α 从 1 到 1e4 只让均值从 −1.43 走到 +0.068，量级远小于预处理带来的 3.2 落差。**但正确的表述是"预处理决定量级、α 决定符号"**，而不是 v3 的"α 是主开关"。

### 2.3 两步链：化合物测的是"哪一类"，感官评的是"这一类该有的样子"

**不再用"60% 介导"这种错误算术**。正确做法是方差分解 + **公平基线**。

**第一步：方差预算**（`SST` = 50 维总平方和）

| 分解层 | 数值 | 含义 |
|---|---|---|
| `SST` | **4164.7** | 总方差 |
| **风格间（between）** | **1513.3 = 36.34%** | 风格本身能承载的方差上限 |
| 风格内（within） | 2651.4 = 63.66% | 同风格个体差异 |

> **口径必须写明**（否则评委会算错）：36.34% 是**合并口径** `Σbetween/ΣSST`；**逐维 η² 的均值是 31.60%、中位 26.08%**。两者都对，但 §2.3 整张表建立在 36.34% 这个分母上，必须声明。

**第二步：四个模型用同一套 CV、同一套 α 网格、同一套有效域限制**

| 模型 | 总 R² | 中位 | 说明 |
|---|---|---|---|
| 化合物（协议：折内缩尾 + 测试折裁剪） | **+0.223** | +0.159 | 主模型 |
| **纯风格 one-hot Ridge（公平基线）** | **+0.182** | +0.111 | 与主模型完全同 CV/同 α |
| 化合物 + 风格 | **+0.242** | +0.173 | 联合 |
| 纯风格 OOF **组均值**（v4 用的基线） | +0.153 | +0.074 | 有噪声，见下 |

**两个方向的增量（这才是对称结论）**：

- **化合物超出风格**：`0.223 − 0.182 = ` **+0.040**（35/50 维为正）
- **风格超出化合物**：`0.242 − 0.223 = ` **+0.019**（42/50 维为正）

> **v4 的 +0.070 高估了 75%**：因为 v4 用的基线是"折内组均值"（0.153），而 22 个风格里 `Faro`(3)、`Brut`(4) 的组均值本身噪声极大。换成同 CV 的 one-hot Ridge（0.182）才是公平比较 → 增量 **+0.040**。
> **论文要写的是这个对称结论**：**化合物能解释 22.3%，风格能解释 18.2%，两者高度重叠——化合物已经包含了大部分风格信息；反过来，风格在化合物之外也还剩一点增量（+0.019）。** 这比单向的"化合物超出风格 +0.070"更难被推翻。

**第三步：层内 R² 取决于分母——不是 α 的问题，是基准的问题**

这一节在 v4–v6 里连错三次：先归因于裁剪，再归因于 α，又把 +0.034 说成"上界"。**真正的问题只有一个——分母。**

层内 R² 的定义是"相对于**风格内均值**的改进"。早先版本的分母用的是**训练折估计出的组均值**（`y − ĝ_group,train`），这等于给基准注入了估计噪声：`Σ(y − ĝ_group,train)² / SS_within = ` **1.234**。也就是说那个分母比真实风格内方差**大了 23.4%**，R² 被凭空抬高约 **0.23**。`Faro`(3)、`Brut`(4) 这种 3–4 个样本的风格，组均值的估计误差高达 20–30%，正是这个偏差的来源。

**标准定义是固定效应口径**（分母用真实组均值 `y − g_true`）。两个分母、同一批 OOF 预测，实测：

| **1000** | +0.050（40/50） | **−0.173**（2/50） |
| 10000 | −0.166（19/50） | −0.439（0/50） |
| `RidgeCV` | +0.080（43/50） | **−0.137**（5/50） |

（两列的分母比值恒为 **1.234**；`RidgeCV` 选中的 α 中位 **2424**，**27.2% 的维度撞到网格上界 1e4**。）

> **正确的表述**：**"按固定效应口径，风格内 R² 在任何正则化强度下都为负——最好的 α=1e3 也只有 −0.173，`RidgeCV` 给 −0.137。风格内不存在可学的化合物→感官映射。"**
> 并且必须撤回早先版本的两句错话：
> - **"最优点 +0.034 是 α 上界"写反了**：+0.034/+0.050 出现在 α=**1e3**，而网格上界 1e4 处反而是 +0.014/−0.166（已停止单调），且 27.2% 的维度恰好卡在 1e4。**"上界"这个词在这里没有意义。**
> - **"任何正的层内 R² 都来自过度正则化"也不成立**：正的层内 R² 全部来自**分母用了训练折组均值**，与正则化方向无关（固定效应口径下 α=1 到 1e4 全负）。
> 附"全样本去均值"算法作对照：**−0.137**，与固定效应口径的 `RidgeCV` 值一致——**这不是巧合，两者都在用真实组均值**，说明固定效应口径才是稳健的。

**第四步：四环节链条**

1. **化合物 → 风格**（22 类，Logistic + 5 折，折内缩尾/标准化）：准确率 **0.484**（v4 记为 0.516，差异来自正则化设置），多数类基线 **0.124** → 化合物谱接近一张风格身份证
2. **风格 → 感官**：风格间承载 **36.34%** 的总方差（合并口径）；且逐维 `R²_d ≈ 1.13·η²_d − 0.13`（r = 0.95），**化合物解释力 ≈ 风格间方差**
3. **化合物 → 感官**：**0.223**；纯风格 **0.182** → **增量 +0.040，真实但很小**
4. **风格内 化合物 → 感官**：固定效应口径下**任何 α 都为负**（最好 α=1e3 仅 −0.173，`RidgeCV` −0.137）→ **风格内部没有可用映射**

> **论文的一句话 motivation**：
> **感官是人的判断，化合物是仪器的读数。二者的对应关系主要不在"个体配方"层面成立，而在"风格"层面成立：化合物先识别出这是哪一类啤酒（0.484），感官再给出这一类啤酒应有的样子（36.3% 的方差在风格之间，逐维 R² 与其高度一致）。风格内部，化合物的解释力在所有正则化强度下都是负的（最好 −0.173）。**
> 因此三个问题成为一条链：**能预测到哪一层（Q1）→ 哪一层能归因、哪一层只能承认不可归因（Q2）→ 只能对"能归因的部分"做逆设计（Q3）。**

### 4.1 交付物规格（12 个样品是**可识别的**，不是"身份未知"）

**v5 的最大漏洞**：v5 写"12 个样品身份未知、与 250 行如何对应附件未说明"，于是 Q1 只能交一张"按卡序排的空白表"。**这是可检验的事实性错误。**

**v6 的证据链（四步，都能在数据里查）**：

1. **`1.csv` 有 `beer` 列**，取值 `1…250` 的**唯一排列**（`sorted(beer) == list(range(1, 251))` 为 `True`），`nunique = 250`
2. **三张表的 `beer` 逐行完全相同**：`(d1.beer.values == d4.beer.values).all()` 与 `(d4.beer.values == d7.beer.values).all()` 都是 `True`；`8.xlsx::Beer Prices` 的 `beer` 也是同一集合
3. **卡片名就是 `beer_1`…`beer_12`**，且每张卡的 **`R3` 是标签 `'Beer#:'`、紧邻的 `S3` 是整数 k**（k = 1…12）—— **不是 v5 说的"`B3` 只有 `Name:` 标签无值"；`B3` 是 `Name:` 的标签格，编号在 `S3` 且是 `int` 不是字符串**
4. **恰有 12 行的 `beer ∈ {1…12}`**：风格依序为 Brut / Low-No alcohol / Blond / Strong ale / Blond / Amber / Saison / Hoppy / Hoppy / Low-No alcohol / Amber / Lambic —— **风格各异，符合"12 个代表样品"的设计**

> **结论**：`Beer#k` ↔ `beer == k`。这是一个**可写进论文、可被评委复算**的映射假设。
> ⚠️ **v7 更正 v6 的两处说法**：
> ① v6 写"若评委不认，退路是按 `beer` 升序前 12 行"。**这句话是空的**——按 `beer` 升序前 12 行就是 `beer == 1…12` 本身，同一条规则。
> ② v6 的"替代证据是行位置 0…11"也**不成立**：实测 `beer ∈ {1…12}` 的行位置是 **`[0, 2, 50, 53, 66, 127, 155, 182, 185, 224, 238, 247]`**，而第 0…11 行的 `beer` 是 **`[10, 86, 2, 83, 40, 247, 48, 165, 124, 207, 155, 141]`**——**两批完全不是同一组样品**。所以"行位置"不是替代映射，只能当作**额外的敏感性检验**（见下表第三列）。
> **真正的三重证据**：卡片编号（`R3` 标签 + `S3` 整数 k）+ 卡名 `beer_k` + "恰 12 行且风格构成符合代表样品设计"。

#### 4.1.3 0–6 分级表（主表用分位数 7 箱，min-max 降附录）

**问题定性**：赛题要"0–6 分制分级评分"，4.csv 是逐维标准化后的连续值（§1.6），**原始 0–6 不可精确还原**。

**v3 的错误（必须删掉）**：曾主张锚点 `0↔0`、`6↔6`，理由是"`max = 6.172` 与 6 几乎重合"。**这个理由是假的**——逐维 `max` 中位只有 **2.26**，6.172 只是 `clove` 一维离群点（该维 sd=0.56）。

**第一步：三种映射的实测对比（v7 新增第三列，据此换主表）**

| 映射 | 0 档占比 | 6 档占比 | 单维等级数中位 | 平均等级 | 像不像评分表 |
|---|---|---|---|---|---|
| v3 原方案 `round(clip(ẑ,0,6))` | **84.6%** | **0.0%** ❌ | 3 | 0.18 | ❌ 全 0 表 |
| v4/v6 的 min-max→[0,6] | **24.4%** | **0.8%** | 7 | **1.61** | ⚠️ 仍严重偏向 0–2 |
| **分位数 7 箱（v7 主表）** | **14.6%** | **14.4%** | **7** | **2.99** | ✅ 两端可达、均值居中 |

**结论：改用分位数 7 箱作为主交付表的映射**。`y_d = QuantileBin7(ẑ_d) − 1`（按逐维 1/7 分位切点装箱，箱号 0…6）。理由：**0 档与 6 档各占约 1/7、平均等级 ≈ 3.0**，这才是"0–6 七级评分表"该有的形状；min-max 只有 0.8% 能到 6 分，等于把"极强"这一档做成稀有事件。
**代价必须自己写出来**：分位数映射**强制每维等级近似均匀**，而真实评分卡上的 `dms` 绝大多数应是 0 分。所以：**分位数映射是"呈现层"的折中，不是对真实评分分布的还原**；min-max 版本放附录作对照，并给出两者 κ = **0.094**（几乎不一致，说明等级标签本身高度依赖映射方式）。

**第二步：诚实的敏感性处理（不承诺 κ）**

评审与我的实测都表明：三对映射的 κ 介于 **0.09–0.51**，**没有一对到 0.7**。因此：

> **不写"κ > 0.7 则稳健"**（该承诺会当场失败）。改写为：
> "三种映射的等级标签一致性 κ 介于 0.09–0.51，**说明 0–6 级标签本身对映射方式敏感、不宜作为推断依据**。所有推断结论（可预测性谱、Top-3 归因、迁移前后比较）**一律基于连续值 `ẑ`**；分级表仅作为题面要求的**交付呈现层**。"
> 并补一条可证明的性质：**任何严格单调变换都不改变两个不同值的先后次序**；只有**取整/分箱引入并列**才改变 Spearman 统计量（实测连续值 vs 分箱后 Spearman 中位 **0.941**，min-max 版 **0.347 → 0.353**）。**这比许诺 κ 更硬，因为它可证明，而且主动暴露了代价。**

**第三步（加分点）**：把 **3.xlsx 评分卡的刻度本身就是 0…6 七级** 作为"等级数=7"的依据写进正文（12 张卡每张都印着 0/1/2/3/4/5/6，每卡 27 个刻度行）。同时声明：**等级数已知为 7，但每个等级对应的浓度区间未知**——这是数据缺口，无法从附件恢复。
> ⚠️ **v7 删掉的一句话**：v6 在第一步写了"0 分 = 无可感知，6 分 = 极强"。**这是把 v3 已被否证的锚点请回来了**（`dms` 的 0 分不是"无可感知"，是"低于该评审员检出阈值"；`clove` 的 6 分也不是"极强"）。**分级标签只声明序关系，不声明绝对含义。**

### 4.2 建模方案

> **先决声明**：分层只是描述性分组（§2.4 显示 one-hot 口径下 **18/50** 维换层、组均值口径 31/50）。**每一维的实际策略由它自己的 CI 与 `freq` 决定，不由层标签决定。**

**统一协议（所有维度都用这一套）**
- 预处理：**折内 winsorize[1,99] → 折内 `StandardScaler`**（`scaler.fit(X_train)`，绝不碰测试折）
- 主模型：`RidgeCV`（α ∈ 1e-2…1e4，40 点对数网格）
- 对照模型：`HistGradientBoostingRegressor`（depth=4, 400 iters, lr=0.05, l2=1.0, leaf=8，**`n_jobs` 不要传**）
- 区间：Bootstrap **B=1000**，重采样样本后重算 R²
- **必报**：逐维 `R²` + 95% CI + `Spearman ρ`

**分组报告**（依据 `Sensory names::DataType`）：

| 组 | 维度数 | 主指标 | 副指标 |
|---|---|---|---|
| categorical | 24 | Spearman ρ | 相邻等级准确率 |
| numeric | 26 | R²（裁剪后） | Spearman ρ |

**实测结论（**v7 重写：v6 的"按风格组织"被数据否证，"接近随机"也是统计错误**）**

v6 在这里有两处硬伤，出自同一个毛病：**给一个否定结果硬安了一个正面解释**。

**第一处：v6 说"共表达模块不是按化学家族组织的，而是按风格组织的"。后半句从未被检验，v7 检验后否证。**

- 只取两端（高 η² 端 20% vs 低端 20%，各 5085 对）：高 η² 对 mean|ρ| **0.173**，低端 **0.163**，**差 0.010**。

## 6. 问题3：风味与"风味指纹"生成

### 6.1 "风味指纹"的定义（v5 收紧）

> **定义**：风味指纹 = 给定风格 `s` 时，由生成模型产出的**化合物谱 `ĉ`** 与其**感官画像 `ŷ`** 的二元组 `(ĉ, ŷ)`。
> 其中 `ŷ` **只包含 §2.2 的 27 个稳定可达维度**；对 **14 个边界维**附条件标注；对 **9 个不可归因维**，`ŷ` 以**风格条件均值 + 区间**给出，并**显式标注"不可由化合物推断"**。
> **不承诺**：不承诺该谱能达到任意指定的个体化感官目标向量——§2.3 已证明风格内映射在**固定效应口径下任何 α 都为负**（最好 −0.173），**该承诺在本题数据上不可能成立**。


### 6.2 生成模型（必须处理检出限的"点质量"，否则生成的谱不是物理的）

- **cVAE**（风格 one-hot 条件），latent 16–32 维；250 样本 → 必须强正则（dropout + KL 权重退火）
- **强基线（必须做，且必须诚实报告）**：风格条件的**高斯 copula / 分位数采样**。这个样本量下它很可能打赢 cVAE
- **⚠️ v7 必改：hurdle（两点）结构，不能直接对连续值建模**
  **问题**：§1.3 已证明 **142 个化合物列有共享检出限地板（−1.817819，占 11.79% 的单元格）**，也就是说这些列的真实分布在**地板处有一个原子（点质量）**。任何连续生成器（cVAE、copula、高斯）**都会产出既非地板、也非真实浓度的"地板之上一点点"的值**——这在化学上是**不存在的浓度**（低于 LOD 就不可能被测到），并且会让 **M2 流形覆盖必输**（真数据有原子质量、生成数据没有）、**M3 也会失真**（生成的浓度既不算超标也不算检出）。
  **做法**（逐列二段式）：
  ```
  对每个有地板的列 c：
    (1) 检出层：p_c(s) = P(检出 | 风格 s)，用 Bernoulli/Logistic 建模；生成时先抽 d ~ Bern(p_c(s))
    (2) 浓度层：仅在 d = 1 时，对 log-conc 分布部分（x > LOD）用 cVAE 生成
    (3) 合成：x_c = LOD_c  if d = 0  else  cVAE 输出（并 clip 到 ≥ LOD_c）
  ```
  **这条不是可选项**：没有 hurdle 的生成器在 142 列上会系统性地产生"物理上不可能"的值，而评委只需要查一次"你的生成数据里有几个值落在 (10^-1.817819 附近) 的窄带里"就能发现。
- 生成后处理：log10 列反变换、linear 列保持原样（§1.2 的量纲纪律）；**反变换后必须把低于各自 LOD 的值回填为 LOD**

### 6.3 评价体系：三条可算指标（不用"感官引导"作主结果）

> **为什么删**：v4 把"感官引导 `L = L_vae + λ‖f(ĉ) − y*‖²`"当主结果。但 §2.3 证明**风格内部的化合物→感官映射在固定效应口径下全为负**，也就是说 `f` 本身在风格内几乎没有预测力——**引导成功与否根本无法验证**。一个不可证伪的模块写进论文，只会被问"你怎么知道它引导成功了"。

**替代的三条指标，全部可算、可复现、可比较**：

| # | 指标 | 定义 | 期望 |
|---|---|---|---|
| **M1 风格保真度** | 用 §2.3 的 22 类风格分类器（准确率 0.484）判断生成样本的**预测风格 == 目标风格**的比例 | `1/N Σ 1[ĉ_argmax f(ĉ) = s]` | **> 0.60**（显著高于分类器自身的 0.484，因为生成样本在风格中心附近） |
| **M2 流形覆盖** | 生成分布与目标风格真实分布的 **energy distance**；并与"随机抽样同风格真实样本"的自助基线比较 | `E(ĉ, X_s) = 2·E‖ĉ−X_s‖ − E‖ĉ−ĉ'‖ − E‖X_s−X_s'‖` | 与自助基线**同量级或更低**（不比真数据更远离真数据） |
| **M3 缺陷超标率** | **逐化合物**的 `P(x_c > τ_c)`，生成样本 vs 目标风格真实样本 | margin `m_c = −log10(x_c/τ_c)`，报 `P(m_c>0)` 及逐化合物表 | **不高于真实样本**（赛题的硬要求） |

**三条指标共同构成"生成质量"的完备描述**：M1 管**风格对不对**，M2 管**像不像真数据**，M3 管**安不安全**。三者都与"感官引导"无关，因此**不需要证明那个不可能证明的东西**。

> **论文里的正面表述**：**"由于风格内部不存在可学的化合物→感官映射（固定效应口径下任何 α 都给出负 R²），我们放弃'给定任意感官目标反解配方'这一不可能的目标，改为生成'风格典型谱'，并用风格保真度、流形覆盖、缺陷超标率三项可计算指标界定其质量。"** —— 这是把限制**变成设计原则**，比硬做一个不可证伪的引导项强得多。

|---|---|---|---|---|---|---|
| DMS | `DMS` | 17.25 | µg/L | log10 | **边界**（R² 0.020，freq 0.67 = 6/9） | **67.2%**（168/250） |
| 双乙酰 | `X2.3.butanedione` | 0.29925 | mg/L | **线性** | 稳定可达（0.101） | **46.5%**（112/241） |
| 4VG | `X4VG` | 0.206333 | mg/L | log10 | 稳定可达（0.212） | **6.4%**（16/250） |
| t2n | `X.E..2.nonenal` | **表中无数值** | — | **线性** | **不可归因**（0.022） | **7.6%**（19/250，用文献阈值 0.11 µg/L） |
| stale hops | — | **表中无数值** | — | — | **不可归因**（0.026） | 无阈值，用 95 分位操作阈值 |

> **t2n 与 stale hops 必须用文献阈值并声明假设**（t2n 常用 0.11 µg/L），或用 **95 分位操作阈值**。**声明比掩盖得分高。**

**v6 关键修正：M3 必须逐化合物报，因为只有一个化合物真正在约束**

v5 写"缺陷约束 = 把生成值投影到 `[地板, τ_c]`"并整体报一个 `P(m>0)`。**真实数据的超阈率差异极大**：

| 化合物 | 超阈率 | 含义 |
|---|---|---|
| **DMS** | **67.2%** | 大多数样品本身就超阈 → **约束必须起作用**，也是"迁移不能恶化"的最强考验 |
| **diacetyl** | **46.5%** | 近一半超阈 → 约束有效 |
| t2n | 7.6% | 少数超阈 |
| **X4VG** | **6.4%** | **近乎空转** —— 生成端投影到 `[地板, 0.206]` 时，94% 的生成值本来就低于阈值 |

> **因此 M3 的正确写法是逐化合物表**：`P(m_c > 0)` × 4 行（DMS / diacetyl / t2n / 4VG），并**明确标注 4VG 这一行"真实超阈率仅 6.4%，该约束在本数据上几乎不激活"**。整体报一个数会把"67% 和 6% 平均成 30%"，看不出约束到底在哪儿起作用。
> **这同时给出 Q3 的一个自然结果**：**"缺陷约束的主要对象是 DMS（67%）与双乙酰（46%）"**，这是一个可写进摘要的定量结论，而"我们约束了所有缺陷化合物"是空话。


### 6.5 跨风格迁移

- **不用均值位移**（会让方差坍缩，且**均值位移恰好会破坏 M2 流形覆盖指标**——这正是 v5 换指标后能自动检验的地方）
- 用 **OT / Sinkhorn** 把源风格化合物分布搬到目标风格经验分布
- 目标：`Pils/Lager → Tripel`，用 **M1/M2/M3 三项同时报告**，其中 M3 要求**逐化合物超标率不上升**

### 6.6 长尾风格

22 类中 `Faro`(3)、`Brut`(4) 样本过少 → 合并或只做描述不建生成模型，**论文里明说**。

## 附录 C：`protocol.py` 的唯一正确实现（必须照抄）

> **关键修正（照抄前必读）**：本函数里的 `np.clip(X[te], lo, hi)` 那一行**不是可选优化，是整个协议的核心**。
> 2×2 实验（§2.1）证明：**如果把这一行的测试折 clip 去掉，只保留训练折 winsorize，结果会从 +0.222 掉到 −12.384**——比完全不缩尾（−2.943）还差 9.4 个单位。
> **原因**：缩尾压低训练折方差 → 标准化时分母变小 → 落在训练支撑集之外的测试样本被放大得更多。**压方差 = 放大杠杆。**
> 所以务必记住：**止血点是"把测试样本限制在训练支撑集内"（输出域约束），不是"缩尾"（方差压制）。** 两者必须成对出现，单用缩尾是负优化。

```python
import numpy as np
from sklearn.linear_model import RidgeCV
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import KFold

ALPHAS = np.logspace(-2, 4, 40)

def oof_predict(X, Y, n_splits=5, seed=0, winsor=(1, 99), alphas=ALPHAS):
    """唯一允许的 CV 实现。

    铁律（每条都被实验验证过，违反任一条都会得到错误结论）：
      1. winsorize 与 StandardScaler 都只在训练折上 fit；
      2. **测试折必须 clip 到训练折的 [lo, hi] 支撑集内**（本次 v5 修正的核心）。
         去掉这一行只保留训练折缩尾 → 平均 R² 从 +0.222 掉到 −12.384。
      3. 任何脚本不得自行调用 StandardScaler().fit_transform(X)（那是泄漏）；
      4. 不做额外裁剪，除非调用方明确要求（见 clip_eval）。
    """
    n, d = Y.shape
    pred = np.empty_like(Y, dtype=float)
    kf = KFold(n_splits, shuffle=True, random_state=seed)
    for tr, te in kf.split(X):
        lo = np.percentile(X[tr], winsor[0], axis=0)
        hi = np.percentile(X[tr], winsor[1], axis=0)
        Xtr = np.clip(X[tr], lo, hi)
        Xte = np.clip(X[te], lo, hi)          # ← 不可删除，见铁律 2
        sc = StandardScaler().fit(Xtr)        # 只在训练折 fit
        A, B = sc.transform(Xtr), sc.transform(Xte)
        for j in range(d):
            m = RidgeCV(alphas=alphas).fit(A, Y[tr, j])
            pred[te, j] = m.predict(B)
    return pred

def clip_eval(y, p, lo=None, hi=None):
    """裁剪到 **训练折** 观测范围后的 R²。裁剪是输出校准，不是模型能力。

    严格做法是把每折训练折的 min/max 传进来（lo/hi）；
    这里默认退回全量 y 的 min/max，是因为实测两者等价：
    v5_clipbounds.py 在全 50 维上比对 逐折训练折 [min,max] 与 全量 [min,max]，
    平均 R² 差 0.0000、逐维最大差 0.0010。论文里须声明用的是哪一种。
    """
    lo = y.min() if lo is None else lo
    hi = y.max() if hi is None else hi
    p = np.clip(p, lo, hi)
    return 1 - np.sum((y - p) ** 2) / np.sum((y - y.mean()) ** 2)

def bootstrap_ci(y, p, B=1000, seed=0):
    rng = np.random.default_rng(seed)
    idx = rng.integers(0, len(y), (B, len(y)))
    p = np.clip(p, y.min(), y.max())
    den = np.sum((y[idx] - y[idx].mean(1, keepdims=True)) ** 2, 1)
    num = np.sum((y[idx] - p[idx]) ** 2, 1)
    v = 1 - num / np.where(den > 0, den, np.nan)
    v = v[np.isfinite(v)]
    return np.percentile(v, 2.5), np.percentile(v, 97.5)
```

## 附录 D：量纲判读函数（三值 + 指数护栏）

```python
import numpy as np

GUARD_EXP = 20.0

def classify_scale(d1, chem, cal, guard_exp=GUARD_EXP, min_pairs=30):
    """返回 {col: 'log10'|'linear'|'log_unknown'}。

    优先级：标定表硬证据 > 结构规则 > 指数护栏降级。

    两个实现要点（都用错了会得到 204/1/26 而不是 182/33/16）：
      1. 判据用 **中位数** 相对误差，不用 **最大值**。标定表里个别行的
         舍入噪声可达 1e-4，用 max 会让 33 个真线性列全部失去硬证据，
         退化成结构规则 → 一律判 log10。实测：max 口径 → 204/1/26（错）；
         median 口径 → 182/33/16（对）。
      2. 要求双方都有值的样本对 >= 30，否则硬证据不可信。
    """
    kind = {}
    for c in chem:
        a = d1[c].values.astype(float)
        if c in cal.columns:
            b = cal[c].values.astype(float)
            m = np.isfinite(a) & np.isfinite(b)
            if m.sum() >= min_pairs:
                with np.errstate(over="ignore", invalid="ignore"):
                    e_log = np.median(np.abs(10 ** a[m] - b[m]) / (np.abs(b[m]) + 1e-12))
                    e_raw = np.median(np.abs(a[m] - b[m]) / (np.abs(b[m]) + 1e-12))
                if e_log < 1e-6:
                    kind[c] = "log10";  continue
                if e_raw < 1e-6:
                    kind[c] = "linear"; continue
                # 标定表把 <LOD 记 0，只在不含 0 的子集上再试一次（CS2 / X4VG）
                mm = m & (b > 0)
                if mm.sum() >= min_pairs:
                    with np.errstate(over="ignore", invalid="ignore"):
                        if np.median(np.abs(10 ** a[mm] - b[mm]) / b[mm]) < 1e-6:
                            kind[c] = "log10"; continue
        v = a[np.isfinite(a)]
        if v.size == 0:
            kind[c] = "log_unknown"; continue
        if (v < 0).any() or np.unique(v).size < v.size:
            kind[c] = "log_unknown" if (guard_exp and v.max() > guard_exp) else "log10"
        else:
            kind[c] = "log_unknown"
    return kind
```
