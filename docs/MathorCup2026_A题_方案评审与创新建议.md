### 2.2 复核**不成立**的三条（必须改）

#### ❌ 错误 1（最严重）：Q1 的"弱信号"基线是假象，会带偏整篇论文

方案 4.1 写：「Ridge（对数域、中位数填补、标准化）5 折：50 维平均 R² = **-2.71**，中位 -0.875，仅 7/50 > 0」，并据此推出"必须引入风格标签、多任务、序数输出"。

我按同样配置复现，定位到了原因：

| 配置 | 平均 R² | 中位 R² | R²>0 的维度 |
|---|---|---|---|
| 未标准化 + alpha=1 | -2624.7 | -1645.3 | 0/50 |
| **标准化 + alpha=1（= 方案的配置）** | **-2.754** | **-2.708** | 1/50 |
| 标准化 + alpha=100 | 0.156 | 0.076 | 31/50 |
| **标准化 + RidgeCV（alpha 逐折自动选）** | **0.216** | **0.153** | **49/50** |

即：方案报告的 -2.71 是 **`Ridge(alpha=1)` 正则化严重不足**的过拟合假象（231 个特征 / 250 个样本），不是数据本身没有信号。

真实情况（5 折、标准化、RidgeCV）：
- 平均 R² = **0.216**，中位 0.153，**49/50 维为正**
- 最好的维度 `acidity` R² = **0.668**；平均 Spearman ρ = **0.405**，29/50 维 ρ>0.3
- 纯风格 one-hot 的 R² = 0.178；**化合物 + 风格 = 0.218（风格增量几乎为 0）**

**后果（这是必须改的原因）**：
1. 论文会自我贬低：明明能做到 R²≈0.22 / ρ≈0.4，却写成"信号极弱、只能靠先验救场"，评审一验就露。
2. 方案的三个补救措施里，**"风格作为协变量"实际零增量**（0.216→0.218）。把它写成"必须引入"会在追问时站不住。风格的正确定位是**分层校准 / 长尾风格冷启动**，不是救场。
3. 指标目标定得太松：相邻准确率目标 >0.80 是按"信号极弱"定的，实际可冲 0.88–0.92；这直接损失了摘要里最有分量的数字。

**建议**：重跑一次可信基线（RidgeCV + PLS + HGB），用真实数字重写 4.1 的"关键认知"，并把"哪些维度可预测、哪些不可"从"缺陷"升级为"发现"（见创新点 1）。

#### ❌ 错误 2：8.xlsx 的 GBM SHAP 是**单模型**，不能反推 50 维的 s_d、m_d

方案 4.2 / Layer 3 方案 C 写：「s_d, m_d 用 8.xlsx 的 GBM SHAP Values 反推（该表同时存了 250 行 SHAP 值与 concentration 值）」。

实际结构：该表 501 行 × 236 列，列为 `data, beer, beer_id, tasting_category_fine + 231 个化合物`，`data` 只有 `SHAP` / `concentration` 两种取值（250+250 行）。**没有任何"目标维度"列** → 这是对 `overall` 单一输出的 GBM 解释，不是 50 个维度各一套。同理 `GBM importance MDI` 只有一列 231 维重要性。

**建议**：把它降级为"总体层面的外部对照"（见创新点 5），不要当作逐维标定工具；方案 C 直接删掉或改成"用 8.xlsx 的 MDI 排名做 Top-3 的第三方一致性检验"。

#### ❌ 错误 3："5 个高堆积列"低估了一个数量级——真实机制是**全局检出限地板**

方案 1.4-A 列了 CS2 / X4VG / octyl_acetate 等 5 列。实测：

- **231 列中有 142 列的最小值完全相同，都等于 -1.8178**（即 10^-1.8178 ≈ **0.0152**）；
- 这 142 列里落在该地板上的单元格共 **6807 个 = 全部单元格的 11.8%**；
- 这些列内部平均 **19.2%** 的样本在检出限，最高 **84.8%**（`X6.methyl.5.hepten.2.one`、`limonene`）；
- 集中在**酒花萜类 / 香料**区块（limonene、beta.phellandrene、meta.cymenene、geosmin、humulene 系列…）。

这不是"5 个列各自的检出限"，而是**仪器一个全局 LOD，让 142 列的左删失被统一截断**。它有 3 个直接后果：

1. **Q1 的缺失处理口径要升级**：从"逐列个案处理"改为"全局 LOD 截断 + 检出指示 + Tobit"，并且要说明这 11.8% 不是随机缺失。
2. **Q2 的图会大面积失真**（方案最大的隐患）：这些列的 Spearman 相关本质是**"共同检出"的点二列相关**。如果直接在 2.csv 上建图，酒花萜类会黏成一个巨大的伪模块，Top-3 会大量落在"共检出"的伪结构上，而你的"化学合理性论证"恰恰要拿模块纯度说事——这里会被问穿。方案只用一句"解读时带上前提"轻轻带过，不够。
3. 反过来，**这是别人不会做的细节**，可以做成创新点（见创新点 2）。

### 2.3 复核发现但方案**完全没提**的关键事实

#### 🔍 遗漏 1：1.csv 与 2.csv 的化合物名体系完全不同，只有 1 个名字重合

- 1.csv 列名是 python 字段名：`acetaldehyde`、`CS2`、`ethyl_2.methyl_butyrate`、`X.E..2.nonenal`
- 2.csv 轴标签是化学全名：`Acetaldehyde`、`Carbon disulfide`、`Ethyl 2-methylbutyrate`
- 231 个名字里**只有 1 个可以直接匹配**；但两个矩阵**按位置逐元素相等**（已用 Spearman 重算验证，误差 1e-16）

**影响**：Q2 的"建图→模块→Top-3→回填到 1.csv 特征→与 6.csv(化学名) 对齐"这条链，方案里默认名字是通的，实际第一步就断。这会让 D1 的建图工作量凭空多出半天。

**建议**：
- 用**位置对齐**建桥（2.csv 第 i 行 ↔ 1.csv 第 i 个化合物列，已证等价）；
- 用 8.xlsx `Sensory thresholds` 的 `chemical_name` 池给节点命名（覆盖 2.csv 的 **212/231**，剩 19 个手工补）；
- 6.csv 的 44 行**全部**是 `chemical_name`，可直接对到 2.csv 的轴 → 二部图可以直接画。
- 这条写进"数据审计"，是第 8 条勘误。

#### 🔍 遗漏 2：8.xlsx 的 `Sensory names` 就是官方维度字典，不该手工造映射表

该表 101 行 = **Trained panel 50 维 + Ratebeer 51 维**，字段含 `R_name / Category / CleanName_Paper / CleanName_PanelFeedback / DataType`。

- 方案附录 A 那张手工映射表，**官方已经给了**；而且方案里担心的 `A_ester_fruity` vs `A_esters_fruity`、`4vg` vs `X4vg` 问题，官方表直接给了 `R_name`，不需要"小写+去除非字母数字"这种脆弱匹配。
- 更重要的是 `DataType`：**Aroma/Flavour 两套共 30 维被标为 `categorical`（0–6 等级），其余 20 维是 `numeric`（连续）**。这意味着方案"50 维混在一起算平均 R²"是**评价口径错误**——30 个等级维度该用 QWK / 相邻准确率，20 个连续维度该用 R² / ρ。混算会系统性低估自己在等级维度上的表现。

#### 🔍 遗漏 3：4.csv 不可逆的**第三条证据**（方案只给了两条，且其中一条推不出结论）

方案用"拟合 z=x·sd+μ 无法收敛到整数格点"论证不可逆，这个方法本身有循环性（假设了线性+等方差）。建议补一个更硬、更好讲的检验：

- 对每列做 k=7 的 1 维聚类，若 4.csv 仍是 7 级离散值的单调变换，则 7 个簇心应**等距**；
- 实测：50 维簇心间距的变异系数平均 **0.43**（`A_malt_all` 0.51、`dms` 0.35、`overall` 0.19），**没有一维接近等距**；
- 且每列唯一值 106–250 个（250 行），说明已连续化。

→ 结论同样成立（不可逆），但证据链更干净：**"若为离散等级的单调变换，7 级簇心必等距；实测全部不等距"**。这条可以直接进论文。

#### 🔍 遗漏 4：Q2 的稳定性实验在排期内跑不完（这是可执行性问题，不是学术问题）

按本机实测（单线程）：

| 方法 | 单维耗时 | 50 维一次重抽样 | B=1000 全量 |
|---|---|---|---|
| Ridge（闭式解） | 0.023 s | 1.1 s | **≈ 18 分钟** |
| HGB（400 iter, depth 4） | 1.84 s | 92 s | **≈ 25.6 小时** |

方案 D3 安排"Bootstrap×1000 + 4 方法"，若 HGB 也在其中，需要 **一天以上**，且还没算 permutation importance 的 30 次重复。

**建议改成三档**：
- 主稳定性实验用 **Ridge/PLS**（18 分钟，B=1000 完全跑得动）；
- HGB **只做一次全样本 permutation importance（repeats=10）**，作为非线性对照，不进 bootstrap；
- 对"既重要又稳定"的 **Top-10 维度**，再做 HGB 的 B=100 精细稳定性（≈ 26 分钟）。

## 四、创新性：现在的"创新"是稳健性，不是洞见

### 4.1 诊断

方案里的"加分项"是：多种重要性方法 + Borda、bootstrap 稳定性、4 种填补消融、α 敏感性曲线、生成+校验+回退闭环。这些**都是评审期待的规范动作**——不做会扣分，做了也不加分。真正让评审记住的是"提出了一个别人没提出的问题"。

同时，方案的 motivation 是"啤酒风味很重要，所以我们做三个任务"，这是任务驱动而非问题驱动。且它的核心叙事（信号弱→需要救场）经复核不成立。

### 4.2 建议的论文主轴：**可预测性 → 结构归因 → 逆设计**（一条论证，不是三个作业）

一句话 motivation：

> **感官是人的判断，化合物是仪器的读数。二者之间的映射强度本身就是一个可研究的对象：如果某些风味维度几乎无法由化学解释，那么"风味指纹"这个概念的有效边界在哪里？**
> 三问正好是这条追问的三步：**能不能预测（Q1）→ 为什么能/不能（Q2 的结构原因）→ 能不能反过来设计（Q3）**。

这条主轴的价值：把方案里"弱信号"这个**缺点**翻转成**发现**，并且让三问的结果互相引用（Q1 的谱 → Q2 的分层变量 → Q3 的目标函数），而不是三个独立章节。

### 4.3 六个可落地的创新点（按投入产出排序）

#### ★ 创新点 1（P0，成本≈1 张图）：把"可预测性谱"作为全文的贯穿量

- 对 50 维各算 CV R²/ρ，得到一条**可预测性谱**（预测：`acidity`/`bitterness`/`body`/`overall` 高，香料与缺陷类低）。
- 用途 A（Q1 的结论）：哪些风味"由化学决定"，哪些"不由化学决定"。
- 用途 B（Q2 的分层）：**"同属一个共表达模块的维度是否更可预测？"** 这是一个可检验的假设（模块内维度平均 R² vs 模块间），把 Q2 从"排序任务"升级为"机制检验"。
- 用途 C（Q3 的约束）：只在"可预测维度"上要求生成谱的感官画像达成度——不可预测的维度上强行拟合是自欺。
- 成本：一张图 + 一次分组检验（Mann-Whitney）。收益：整篇论文有了脊梁。

#### ★ 创新点 2（P0，成本≈1 天）：检出限地板 → 共检出伪相关 → 稳健图

- 把 142 列共享 LOD 的事实显式建模：建**三档图**——① naive Spearman（2.csv 原样）；② **检出条件相关**（只在双方都检出的子集上算，样本量不足则标记）；③ **tetrachoric / 二值潜变量相关**（把"检出"当观测）。
- 量化对比：三档图的模块数、模块化学家族纯度、Top-3 差异率。
- 预测结论：naive 图会把酒花萜类整块粘成伪模块，校正后模块更细、化学纯度更高。
- **这是本方案最值得投的创新**：它同时解决了 Q2 的"化学合理性会被问穿"的风险，并给出一个别人没有的定量发现。

#### ★ 创新点 3（P1，成本≈2 天）：Q1 用"零膨胀有序模型"替代"回归 + 分位数映射"

- 方案的分位数映射 `grade = round(6·F_d(z))` 有一个硬伤：**它强制每一维的等级在 0–6 上均匀分布**。但 `dms`（缺陷）在真实评分卡上绝大多数是 0 分，均匀化等于系统性高估缺陷。这一点方案自己没意识到（只写了"假设单调"）。
- 建议主方案：**零膨胀有序 probit**——`P(grade=0)` 单独用 logistic 建模（零质量），`P(grade=k | >0)` 用 6 个可学阈值的有序模型。它天然处理感官评分的零堆积，且直接输出 `P(grade=k)`，可给置信区间。
- 把分位数映射降级为 baseline，用"等级分布 KL + QWK"证明有序模型更好。
- 成本不高（`statsmodels` 的 `OrderedModel` + 自写 zero-inflated 外层，或直接手写 6 阈值 + 梯度），但**方法论上比"分位数映射"高一个档次**，而且回答的正是题名里的"0–6 分制分级评分"。

#### ★ 创新点 4（P1，成本≈2 天）：Q3 从"生成"升级为"逆设计闭环"，迁移用最优传输

两个改动：

**(a) 生成目标加"感官可达性"**：现在 `p(C|s)` 只能生成"像这个风格"的谱，评审会问"那你比直接重采样强在哪"。改成条件生成 **`g(s, 感官目标向量) → C`**，用 Q1 的可微模型 `f` 做梯度引导（`L = L_vae + λ‖f(Ĉ) − y_target‖²`）。这样生成器有了**功能价值**：给定"我想要更柑橘、更少双乙酰"的感官目标，反解化合物谱。这才是"风味指纹"的正确定义（**指纹 = 风格级的化合物原型 + 感官画像的联合签名，且可反解**）。

**(b) 迁移用最优传输而不是均值位移**：`z' = z + α(μ_tgt − μ_src)` 会让所有迁移样本向同一个点收缩（方差坍缩），方案没提这个已知缺陷。改成在 PCA 子空间（20–30 维，250 样本上可精确求解）做 **Sinkhorn / 精确 OT**，把源风格的**分布**整体搬到目标风格分布——保多样性、保样本间结构，且 α 变成"OT 插值系数"（`(1-α)·z_src + α·T(z_src)`），帕累托曲线更漂亮。

**(c) 缺陷指标加"裕度"**：现在只数"超阈值项数"，漏掉"从 0.9τ 恶化到 0.99τ"这种擦边。改为 `margin_c = −log10(x_c/τ_c)`，报告配对样本的 margin 变化（Wilcoxon），比 0/1 计数敏感得多。

#### ★ 创新点 5（P2，成本≈半天）：用 8.xlsx 的现成 GBM 当"外部裁判"

- 你们的 Top-3 与官方 `GBM importance MDI` 的 top-k 重合度 = 一个**第三方证据**，比自证硬得多（"我们的结论与赛题方提供的基线模型一致度 X%"）。
- 注意口径：只能做**总体层面**（overall）的对照，不是逐维（见错误 2）。

#### ★ 创新点 6（P2，成本≈半天）：全文带不确定性

250 样本下任何点估计都该带区间：Q1 给预测区间、Q2 给 Top-3 入选频率的 95% CI、Q3 给生成样本的感官画像分布。摘要里写"R²=0.22 [0.15, 0.29]"比写"R²=0.22"成熟一个档次。这项几乎零成本，但显著提升"科学感"。

## 五、分问题改进清单

### Q1（感官评分）
1. **重做基线**（必修）：RidgeCV + PLS + HGB，得到真实 R²≈0.22，重写"任务难度"叙事。
2. **口径拆分**：30 个 categorical 维度用 QWK/相邻准确率/等级分布 KL；20 个 numeric 维度用 R²/ρ。分开报，不要混算。

5. **补一个"可预测性谱"图**：横轴 50 维排序，纵轴 R²，标注维度类别（香气/风味/主体/缺陷/香料）——一眼看出"化学能解释什么"。

### Q2（Top-3）
1. **先建名字桥**（必修，D1 第一件事）。
2. **三档图对比**（naive / 检出条件 / tetrachoric），作为"化学合理性"的第一道论证。
3. **Borda 改为"主判据 + 对照"**：M1/M2 决定 Top-3，M3/M4 只报一致性。
4. **稳定性补"设定敏感性"**：τ ∈ {0.10, 0.124, 0.15} × 是否校正检出 × 是否控制风格，做 2×3 的稳定性热图。评审最爱问"你换个阈值结论变不变"，主动给答案。
5. **随机基线要补齐**：现在只给了 Jaccard 的随机基线 0.02，但 S（入选频率均值）的判据 0.6 没有参照。随机 3 元子集的期望 f = 3/231 ≈ 0.013，应写进去。
6. **多重比较**：11550 次检验 + Top-3 选择性推断，至少用 BH 控制 FDR 并说明"Top-3 是选择性估计，已用 stability selection 的频率阈值 0.6 做筛选"。

### Q3（生成/迁移）
1. **定义"风味指纹"**（必修，概念悬空是硬伤）：建议定义为"风格级的化合物原型向量 + 感官画像 + 二者在共表达模块上的分布"，并给一个可比对的距离。
2. cVAE 加**感官引导**（创新点 4a）。
3. 迁移换 **OT**（创新点 4b），保留均值位移作 baseline。
4. 缺陷指标加 **margin**（创新点 4c）。
5. 生成质量评估补**边缘分布检验**（每维 KS 统计量的分布），现在只有判别器得分 + PCA 叠加图，偏定性。
6. 重采样 baseline 要"公平"：现在说"极难打败"，那就把它做成主 baseline 并**明确报告 cVAE 相对它的增益/劣势**——诚实反而得分。
